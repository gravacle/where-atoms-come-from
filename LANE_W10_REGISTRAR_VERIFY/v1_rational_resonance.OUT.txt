== PROOF ==
  Resonance means: EXISTS integers (m,n) != (0,0) with m*f + n*c = 2*pi*j for some integer j.
  If f and c are RATIONAL reals, m*f + n*c is rational for all integer m,n.
  2*pi*j is irrational for every j != 0 (pi transcendental), so j = 0 and we need m*f+n*c = 0.
  Write f = p/q, c = r/s in lowest terms. Then (m,n) = (r*q, -p*s) is a nonzero integer
  solution: r*q*(p/q) - p*s*(r/s) = r*p - p*r = 0.  EVERY RATIONAL (f,c) IS EXACTLY RESONANT.
