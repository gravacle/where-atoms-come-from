## T1 — DURABILITY IMPLIES UNWRITABLE

**Theorem.** Let `L[ρ] = -i[H,ρ] + Σ_k ( L_k ρ L_k† − ½{L_k†L_k, ρ} )` be any GKSL generator, `H`
Hermitian, `L_k` arbitrary. Let `R` be **normal**. If `[H,R] = 0` and `[L_k,R] = 0` for every `k`,
then `d⟨R⟩/dt = 0` for **every** state.

**Proof.** `d⟨R⟩/dt = Tr(R·L[ρ])`.
The coherent part gives `−i Tr(R[H,ρ]) = −i Tr([R,H]ρ) = 0`.
For each `k`: `Tr(R L ρ L†) = Tr(L† R L ρ)`, and `[L,R]=0` gives `L†RL = L†LR`, so this is
`Tr(L†L R ρ)`. The anticommutator gives `½Tr(RL†Lρ) + ½Tr(L†L R ρ)`. **`R` normal ⟹ `[L†,R] = 0`**
(below), hence `[L†L,R] = 0`, hence `Tr(RL†Lρ) = Tr(L†LRρ)`, and the anticommutator term equals
`Tr(L†LRρ)`. The two cancel exactly. ∎

**Lemma (`R` normal, `[L,R]=0` ⟹ `[L†,R]=0`).** A normal `R` has an orthogonal eigenbasis. `L`
commuting with `R` preserves each eigenspace, so `L` is block diagonal in that basis; therefore so is
`L†`, which commutes with `R`. ∎

> **NO LATTICE, NO GAUGE GROUP, NO DIMENSION, AND NO UNITARITY OF THE JUMP OPERATORS ENTERS.** The
> program only ever measured the case of unitary jumps.

**Hypotheses verified at their edges** (`pa1_verify.py`, random operators, exact simultaneous
diagonalisation): `R` unitary and `R` normal-but-not-unitary, with **non-unitary** jumps, `D = 4…12`
— all commutators `~1e-15`, `max|d⟨R⟩/dt| ≤ 1.2e-15`. Dropping `[H,R]=0` breaks it (`0.91`);
dropping `[L,R]=0` breaks it (`17.4`).

**REMARK, and it makes the hypothesis nearly free.** If `H` is Hermitian with **non-degenerate**
spectrum and `[H,R] = 0`, then `R` is diagonal in `H`'s orthonormal eigenbasis and is therefore
**automatically normal**. Normality is not an extra physical assumption in any generic setting.

**CAVEAT.** The non-normal counterexample in `pa1_verify.py` is **not clean** — that construction
also breaks `[H,R]=0`, so it does not isolate non-normality. It cannot easily be made clean, for the
reason in the remark: a non-normal `R` commuting with a Hermitian `H` requires `H` degenerate.

## T2 — READING REQUIRES A CLOSED PATH

**Theorem.** In a gauge theory on a graph with link variables `U_ℓ ∈ G` transforming as
`U_ℓ → g_a U_ℓ g_b⁻¹` for `ℓ = (a,b)`, the ordered product `W(γ)` along a path `γ` from `a` to `b`
transforms as `W → g_a W g_b⁻¹`. It admits a gauge-invariant function of the link variables alone
**iff `a = b`**, i.e. iff `γ` is closed.

**Proof.** For `a ≠ b`, take `g_a = e` and `g_b` arbitrary: `W → W g_b⁻¹`, so no function of `W`
alone is invariant. For `a = b`, `W → g_a W g_a⁻¹`, and class functions of `W` (in particular
`Tr W`) are invariant. ∎

**Corollary.** The gauge-invariant algebra generated by link variables consists of closed-loop
holonomies. **A probe acquiring information by parallel transport along an open path acquires
nothing gauge-invariant.**

**This is W-37's cut-ring control**, which returned **exactly `0.000000`** at every time. The
measurement is an instance of the theorem, not evidence for it.

## T3 — CAPACITY = m − 1

**Theorem.** Let the regions be subsets of a plaquette set `P`, `|P| = m`, so they form `GF(2)^m`,
with boundary map `S ↦ bd(S)` (links lying in an **odd** number of the plaquettes of `S`). Call a
set of regions *simultaneously protectable* if some link lies on **none** of their boundaries. Then

```
   capacity = m − 1   if every link lies on at least one plaquette
   capacity = m       if some link lies on none
```

**Proof.** `bd` is linear over `GF(2)`. For a fixed link `ℓ`, `f_ℓ(S) = bd(S)_ℓ` is a **linear
functional** on `GF(2)^m`, so the regions protectable via `ℓ` form `ker f_ℓ`, of dimension
`m − rank(f_ℓ)`. `rank(f_ℓ)` is `0` iff no plaquette contains `ℓ`, and `1` otherwise. Capacity is the
maximum over `ℓ`. ∎

> **PLANARITY, DIMENSION, LATTICE STRUCTURE AND GAUGE GROUP PLAY NO ROLE.**

**Verified** (`pa3_verify.py`) on the `3×3` patch, four disconnected squares, a **tetrahedron**, a
**cube surface**, and six random complexes including several with orphan links — **10 of 10 agree**,
and the orphan-link hypothesis is confirmed to be the one doing the work (`m=2`: capacity `1` without
an orphan, `2` with one).

## T4 — LEGIBILITY IS THE BOUNDARY-TOUCHING COUNT — **W-46's COEFFICIENT WAS WRONG**

**Reduction.** A region `A`'s records are subsets of its plaquettes; an outside observer holds
operators built from outside plaquettes; the pairing `⟨T,S⟩ = |bd(T) ∩ bd(S)| mod 2` is, for lattice
plaquettes, exactly the **bipartite adjacency between outside and inside plaquettes**. So

```
   legibility = rank_GF(2) (outside × inside adjacency)
              = |A| − dim{ S ⊆ A : bd(S) touches no link shared with the outside }
```

**The kernel is the plaquettes invisible from outside**, and for an `n×n` block it is exactly the
interior:

```
    n   |A|=n²   legibility   invisible   (n−2)²   4(n−1)
    2       4            4           0        0        4
    3       9            8           1        1        8
    4      16           12           4        4       12
    5      25           16           9        9       16
```

> **`invisible = (n−2)²` — precisely the plaquettes touching no outside plaquette.
> `legibility = 4(n−1)` — the boundary-touching count, LINEAR in `n`.**

**W-46 REPORTED `2n−1` AND THAT NUMBER IS WITHDRAWN. Its region was placed at the lattice CORNER**,
so part of `A`'s boundary faced the lattice edge rather than any outside plaquette. Re-running that
geometry reproduces `3, 5, 7` exactly; placing the same region in the interior gives `4, 8, 12`.

> **THE CONCLUSION SURVIVES AND IS STRONGER: storage scales with AREA (`n²−1`), legibility with
> PERIMETER (`4n−4`), and the mechanism is now exact rather than fitted — what is invisible is
> precisely the interior.** Only the coefficient changes.

**STILL NOT A CLOSED THEOREM.** The rank has shape-dependent dependencies: the `plus` pentomino has
all five cells touching the outside yet legibility `4`, while `3×3`-minus-centre has all eight
touching and legibility `8`. **`legibility = boundary-touching count` is exact for rectangles and
fails for some shapes.** The general statement is the kernel characterisation above; the closed form
is established only for rectangular blocks.
