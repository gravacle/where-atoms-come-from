## 1. Physics question and bounded answer

Can an existing public experiment substitute for a laboratory matched KEEP/BREAK
test of retained memory lineage or gravity history?

The strongest executable public near-match in the documented audited candidate
set outside the already exhausted HUST and K5 lanes is Bense and van Hecke's
same-apparatus corrugated-sheet
experiment. Its official release contains chronological compression and force
records for repeated loops, return-point memory (RPM), an accumulator protocol,
and a weak-RPM-break protocol. The frozen diagnostic has now been executed on
all four selected CSVs.

The answer is two-part:

1. **Yes for a mechanical history diagnostic.** The deposited apparatus has
   reversible loading paths with branch-dependent load trajectories, repeated
   input accumulation, and publication-owned force-jump events. This is real,
   executable history-dependent mechanics in one specimen/apparatus channel.
2. **No for a causal memory-lineage or gravity-history contrast.** The selected
   packet does not join an authenticated memory-lineage coordinate, sufficient
   conventional-confound state, a paired surgical KEEP/BREAK intervention, and
   one common later query. Therefore the constitutive-lineage contrast is not
   identified. The missing fields are not a zero result and do not count
   against memory lineage or gravity formation.

This is the public-data frontier of the audited candidate set, not proof that
no other public dataset exists and not a request for more model machinery.

## 2. Primary source and source ownership

The sole physics source is the primary article:

- H. Bense and M. van Hecke, “Complex pathways and memory in compressed
  corrugated sheets,” *PNAS* 118, e2111436118 (2021),
  [doi:10.1073/pnas.2111436118](https://doi.org/10.1073/pnas.2111436118).
- Author-institute primary PDF:
  [AMOLF repository](https://ir.amolf.nl/pub/10492/16760OA.pdf).
- Official public data project:
  [Figshare project 127250](https://figshare.com/projects/Complex_pathways_and_memory_in_compressed_corrugated_sheets/127250),
  CC BY 4.0.

The source paper describes a hysteron as a two-state element whose state at an
intermediate compression depends on drive history; RPM is return to a previous
state on revisiting an extremum. It reports repeated-loop RPM, an accumulator
that changes over nominally repeated cycles, and a strict RPM violation. Its
methods use an Instron 3366, axial displacement control better than 10 microns,
a 5-N sensor used accurately to 10 mN, and a stated 1 mm/min loading speed with
a slower-speed check.

`SOURCE_CUSTODY.json` binds the exact Figshare file IDs, repository MD5 values,
local SHA-256 values, byte counts, and the primary PDF. All eight acquired
objects pass custody. Large image and movie objects were excluded before
outcome access because they are not required for the frozen drive/load
estimand. The wider project advertises image objects that may help reconstruct
groove states. They were not needed to establish the decisive obstruction:
even a reconstructed state series would not add a surgical paired intervention,
conventional-confound match, writer-off/hold, or common later query.

The local freeze and access declarations are internally frozen according to
project custody. They are not externally timestamped or independently
registered evidence of historical access order.

## 5. Identifiability theorem and theory typing

### Definitions

Let the deposited observables be

\[
O_t=(t,U_t,F_t),
\]

and let $H_t=H(U_{\le t})$ denote the known prior drive route. Separate the
future-active state into the target memory coordinate

\[
L_t=\text{authenticated event-keyed groove-state/transition lineage}
\]

and the conventional-confound vector

\[
C_t=(U_t,F_{0t},\text{stress/strain, geometry/damage, energy/work/heat,
actuator, support, acoustic, read and EM state}),
\]

where $C_t$ expressly excludes $L_t$. The constitutive target is

\[
\beta_L(q;c)=
\mathbb E[Y_q\mid {\rm do}(L=L_{\rm KEEP}),C=c,Q=q]
-
\mathbb E[Y_q\mid {\rm do}(L=L_{\rm BREAK}),C=c,Q=q].
\]

KEEP and BREAK deliberately differ in authenticated $L$ while conventional
$C$, any declared marginal occupation, and the future query are matched or
bounded. The program does **not** demand that all future-active physical state
be identical.

### Proposition

From a chronological release containing only $O_t=(t,U_t,F_t)$, with no
event-bound $L_t$, no sufficient $C_t$, no paired KEEP/BREAK intervention, and
no event-bound common query $q$, $\beta_L$ is not identifiable.

### Proof

Construct two structural descriptions of the same observed trace.

- In model $M_L$, let the route write $L_t=H_t$, hold conventional $C_t$
  fixed, and write $F_t=f(U_t,L_t)$. The constitutive memory contrast can be
  nonzero.
- In model $M_C$, hold $L_t$ fixed, let an unobserved conventional state carry
  the route, $C_t=H_t$, and write $F_t=f(U_t,C_t)$. The constitutive memory
  contrast is zero.

Both models generate exactly the same joint law for every deposited
$(t,U,F)$ sample, including every loop and force jump, but they assign different
values to $\beta_L$. The public observables cannot distinguish these
observationally equivalent models. Without a common later query, even a
candidate endpoint match cannot supply the requested post-intervention
contrast. Therefore $\beta_L$ is not identified. QED.

The proposition does **not** say that history or memory is unreal. It says the
released force trace cannot decide whether retained history is carried by the
declared memory-lineage coordinate rather than an unmeasured conventional
mechanical state.

For completeness, the originally frozen D3 asks about a different quantity: a
direct residual of remote route history conditional on a *complete*
future-active state $W=(L,C)$. The selected data cannot estimate that residual.
More fundamentally, if $W$, dynamics, and the query channel are genuinely
complete and identical, state sufficiency makes the same-channel residual
zero. That trivial complete-state comparison is not the constitutive
memory-lineage test.

## 7. Minimal concrete data-release target

The first load-bearing missing object is an event-keyed
`MATCHED_ENDPOINT_QUERY_TABLE`. Each row pair must bind:

\[
({\rm block}, {\rm route}, {\rm endpoint\ event},L,C,
 {\rm writer\ state}, {\rm query\ id}, Y_{q}, {\rm covariance}).
\]

The smallest decisive mechanical acquisition uses the same specimen and
randomized paired routes:

- KEEP: retain the authenticated target lineage $L$;
- BREAK: surgically erase, scramble, or reprepare $L$ while matching the
  declared marginal occupation when appropriate;
- independently image or otherwise bind the declared per-groove
  state/transition ancestry vector $L$ to each event;
- match or bound conventional $C$ separately: Extension, baseline Load,
  internal stress-strain, geometry/damage, support, actuator state, energy,
  work, heat, acoustic loss, read disturbance, and EM conditions;
- turn the writer off, apply a registered settling interval, then deliver one
  identical subthreshold future query;
- repeat independent blocks and release the joint covariance/noise object.

To turn this into a gravity-history test, the acquisition additionally needs a
remote, compositionally distinct force or clock probe and event-keyed custody
of source energy-stress and supports across KEEP, BREAK, hold, and query. The
Newtonian and environmental nuisance channels must be predeclared. The public
Bense release contains none of those gravity observables.
