# Theory-typing amendment 002 -- constitutive memory versus history beyond state

**Recorded:** 2026-08-27, after the first production result and before sealing.

## Hostile-audit finding

The frozen D3 search required the complete present hysteron/internal state to be
identical while prior route history differed. That is a legitimate search for
a *direct residual history effect beyond a complete state description*, but it
is not the program's constitutive memory-lineage estimand. Memory lineage may
itself be a future-active component of present physical state. If the complete
future-active state and the later channel were truly identical, state
sufficiency would make a different same-channel response impossible.

This amendment corrects the theory typing without changing any numerical
diagnostic, selecting an effect, or reopening the frozen CSV set.

## Correct split

Define the target memory coordinate

\[
L_t=\text{authenticated, event-keyed retained groove-state/transition lineage}
\]

and define a conventional-confound state that expressly excludes that target,

\[
C_t=(U,F_0,\text{internal stress/strain, geometry/damage, energy, work, heat,
acoustics, actuator, support, read and EM state}).
\]

The constitutive target changes (L_t) by a declared KEEP/BREAK intervention
while matching or bounding (C_t), the marginal occupation/count when
appropriate, and one later query. It does **not** hold all of physical state
fixed.

The frozen D3 result is retained and relabeled
`DIRECT_RESIDUAL_HISTORY_EFFECT_CONDITIONAL_ON_COMPLETE_PRESENT_STATE`. The
constitutive frontier is separately labeled D4. In the selected CSV packet,
neither an event-bound (L_t) nor sufficient (C_t), randomized KEEP/BREAK,
or a common future query is deposited. The wider Figshare project advertises
image objects that may help reconstruct groove states, but the selected small
packet and scripts do not bind an immutable complete lineage coordinate to the
four CSVs. Even a later image reconstruction would not supply the absent
surgical intervention, conventional-confound match, writer-off/hold, or common
query.

## Identifiability consequence

The observed law of ((t,U,F)) is compatible both with a model in which the
route writes an authenticated memory coordinate (L) that changes response
and with a model in which (L) is inert while an unmeasured conventional state
(C) changes response. These models give the same public trace but different
KEEP/BREAK contrasts on (L). That is the relevant public-data obstruction.
It is not a claim that history, mechanical memory, or lineage is absent.
