# Hostile audit -- public mechanical-memory history frontier

**Audit scope:** theorem, frozen protocol, source custody, numerical analyzer,
causal typing, and claim ceiling.  
**Disposition:** `PASS_AFTER_TWO_MATERIAL_REPAIRS_AND_EXPLICIT_DEVELOPMENT_CEILING`

This document records a builder-side adversarial audit plus a material
theory-typing objection raised independently by the root program reviewer
before sealing. It does not label the public experiment an independent
validation of URFT or gravity formation.

## 1. Candidate-selection attack

**Attack.** Bense may have been selected because its force curves looked
favorable, or another public source may already contain the causal test.

**Resolution.** `PREREGISTRATION.md` froze Bense from the prior metadata-only
mechanical candidate audit before this lane downloaded any selected CSV body.
That audit calls it the strongest *public executable* near-miss because the
release has stable DOIs, raw chronological drive/load, scripts, license, and
hash custody. HUST and K5 already have sealed dedicated executions and do not
contain the requested lineage intervention. Page--Geilker and the bounded
second public search were previously proven rank/field-incomplete. Chen has a
stronger physical lifecycle but no joined public event acquisition; Gupta
omits load-bearing data. This lane therefore executes a new public physical
root rather than recycling HUST/K5.

The claim is not that no unknown dataset exists. It is that the strongest
already-audited executable candidate has been run and still lacks the named
causal object.

## 2. Outcome-access and preregistration attack

**Attack.** The execution could be mislabeled prospective.

**Resolution.** The file set, branch diagnostic, event custody, D3 search, and
claim ceiling were frozen before outcome download. During schema inspection,
basic ranges, branch counts, and the official event rule were viewed before
the production executable existed. `SCHEMA_AMENDMENT_001.md` discloses this
and freezes duplicate, integration, zero-step, and event conventions. The lane
is explicitly `RETROSPECTIVE_DEVELOPMENT_AFTER_DISCLOSED_SCHEMA_INSPECTION`.
No held-out or prospective-validation claim survives.

The freeze/access records are local self-declarations without an external
timestamp or public registration. Their hashes establish current byte
integrity, not independent proof of historical access order. Publication must
therefore say “internally frozen according to project custody,” and the
candidate claim is limited to the documented audited search set rather than
all public datasets.

## 3. Branch-functional attack

**Attack.** An overlap integral can be biased if exact shared points do not
include both overlap endpoints or if its normalization uses force values
outside the overlap.

**Material repair.** The first implementation did both: it integrated only the
exact intersection yet divided by the full overlap width, and used the full
branch force range. Before sealing, the analyzer was repaired to append both
closed-overlap endpoints by within-branch interpolation and to compute the
pooled range only from compared overlap values. `RESULT.json` was fully
regenerated. The independent verifier recomputes every one of the 97
opposite-branch comparisons, including pointwise digests and all metrics.

## 4. Complete-state versus constitutive-lineage attack

**Attack.** Frozen D3 held the complete hysteron/internal state fixed while
changing prior history. That asks for a history residual beyond state, not the
program's constitutive memory-lineage effect. If the complete future-active
physical state is identical, a same-channel experiment cannot distinguish the
histories.

**Material repair.** `SCHEMA_AMENDMENT_002_THEORY_TYPING.md` separates:

- the target memory coordinate (L_t), deliberately changed by authenticated
  KEEP/BREAK; and
- the conventional-confound state (C_t), matched or bounded while explicitly
  excluding (L_t).

The frozen complete-state D3 is retained but relabeled as a non-target direct
residual. D4 states the actual constitutive identifiability frontier. The
theorem now proves observational equivalence between an (L)-mediated model
and a conventional-(C)-mediated model. It no longer asks for all physical
state to be fixed.

## 5. Public image/state-custody attack

**Attack.** The full Figshare project advertises raw/derived image objects, so
“the release has no state word” may be too broad.

**Resolution.** The claim is narrowed to the **selected joined CSV packet**:
the four CSVs contain only Time, Extension, and Load. The small official
scripts depend on unavailable local modules and directory ordering, and do not
immutably bind a complete state/lineage word to these four files. Large image
objects might support a later groove-state reconstruction, but they cannot
create the absent randomized surgical intervention, matched conventional
state, writer-off/hold, common query, or covariance. They are therefore not
load-bearing to the causal obstruction and were not downloaded.

## 6. Force-event/state-word attack

**Attack.** A force jump might be silently treated as a hysteron bit or a
complete state word.

**Resolution.** The analyzer implements only the exact public-script proxy

\[
|\Delta F|>0.0079\ {\rm N},\qquad \Delta i>15
\]

and reports every retained index, time, drive, pre/post load, delta, and branch.
It labels these `candidate_force_events_not_a_complete_hysteron_state_word`.
No Hamming closure is invented. Zero events in the three-loop file are handled
without the public script's empty-array crash.

## 7. Numerical and uncertainty attack

**Attack.** A single chronological trace with autocorrelation might be treated
as independent samples or used for a significance claim.

**Resolution.** The result reports deterministic descriptive functionals only.
The 97 branch comparisons reuse four chronological traces and are not 97
independent trials; same-apparatus status is per file, not a cross-file joined
trial.
It does not compute p-values, confidence intervals, effective sample counts, or
joint coverage. Trial IDs and a covariance/noise object are absent and fail an
explicit gate. Repeated branches do not become independent validation roots.

## 8. Causal-proof attack

**Attack.** Path dependence at fixed drive could be presented as proof of
lineage constitution.

**Resolution.** Ordinary hysteresis already gives branch dependence. The
theorem constructs two observationally equivalent models:

\[
M_L:\ L=H,\ F=f(U,L),\qquad
M_C:\ C=H,\ F=f(U,C).
\]

They reproduce the same public ((t,U,F)) law but have different constitutive
KEEP/BREAK contrasts on (L). Because neither event-bound (L), sufficient
(C), nor a common query is deposited, the causal coefficient is not
identified. This is a proof about the released observable sigma-algebra, not a
claim of zero memory physics.

## 9. Gravity-overclaim attack

**Attack.** A mechanical-memory response could be called gravity emergence.

**Resolution.** No remote force/clock/light probe, conserved source-stress
ledger, common metric channel, or gravitational calibration exists in this
packet. The status ends in `NO_GRAVITY_TEST`; the result excludes URFT,
gamma, metric, RGRL, GFT, and gravity confirmation/refutation. The theorem
names the additional remote-probe/source-stress release needed for a future
gravity-history test.

**Resolution.** Seven Figshare objects are bound to repository MD5, SHA-256,
and bytes; the author-institute PDF is bound to SHA-256 and bytes. CSV headers,
units, row counts, time monotonicity, branch segmentation, all event indices,
all branch comparisons, return extrema, claim ceilings, and deterministic

bind the final packet. No canonical model, program register, or git state is
edited by this lane.
