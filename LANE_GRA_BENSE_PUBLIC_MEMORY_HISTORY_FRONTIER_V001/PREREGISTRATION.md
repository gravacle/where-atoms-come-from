## 1. Why this candidate is selected

The existing mechanical JOINT_SEED audit identified the Bense--van Hecke
corrugated-sheet project as the strongest public executable near-miss:
synchronized compression and force, localized hysteron transitions, repeated
cycles, public scripts, versioned child DOIs, CC BY 4.0 terms, and
repository-supplied checksums. This selection precedes outcome access and is
not based on the sign or size of any contrast.

The primary source is H. Bense and M. van Hecke, “Complex pathways and memory
in compressed corrugated sheets,” PNAS 118, e2111436118 (2021),
DOI 10.1073/pnas.2111436118. The official public project is Figshare 127250.

This lane is deliberately narrower than URFT confirmation and narrower than a
gravity-emergence experiment. It asks whether an actual public mechanical
memory acquisition can supply a matched reversible history contrast and, if
not, exactly which causal fields are absent.

Column ownership is fixed in this order:

1. an explicit CSV header;

3. the primary article or supplement.

If these sources do not identify the drive coordinate, chronological sample
order, and every claimed response/state column without value-dependent

because it gives a larger or cleaner effect.

## 4. Frozen diagnostics

### D1 -- reversible branch/history diagnostic

For each eligible chronological series, segment the public drive coordinate
\(U\) into maximal monotone branches. Zero increments inherit the nearest
nonzero direction; a branch shorter than three distinct \(U\) values is
discarded. On every pair of oppositely directed branches with overlapping
drive support:

1. use the union of exact repeated \(U\) values when available;
2. otherwise use a deterministic 101-point grid over the closed overlap and
   piecewise-linear interpolation within each branch only;
3. report the branchwise response difference for every script-owned continuous
   response and the Hamming difference for every script-owned binary state
   word;
4. report the overlap-integrated absolute difference divided by the pooled
   response range; if the range is zero, report zero only when the numerator is
   also zero, otherwise UNSCOREABLE.

This can establish physical path dependence at fixed external drive. It cannot
by itself establish a lineage-only effect because hidden stress and internal
state may differ.

### D2 -- return and repeated-input custody

For RPM.csv and WeakRPMBreak.csv, enumerate every chronological revisit of a
previous local drive extremum. Report the exact state word and every owned
continuous response at the first and returning visit. A return is state-closed
only when the complete deposited state word agrees exactly.

For Accumulator.csv, split the sequence only at script-owned cycle boundaries.
Report the state word before and after every nominally repeated drive cycle and
the Hamming transition. No cycle may be omitted. This is a repeated-input
memory diagnostic, not a causal KEEP/BREAK comparison.

For 3_loops_SampleA.csv, report cycle count, common drive overlap, and
cycle-to-cycle response differences. It is an apparatus/repeatability check,
not an independent validation root.

### D3 -- strongest possible matched-history test

Search exhaustively for two route endpoints satisfying all public equalities:

\[
U_A=U_B,\qquad W_A=W_B,\qquad F_A=F_B
\]

at deposited precision, where \(W\) is the complete script-owned state word
and \(F\) is the complete script-owned continuous mechanical response vector.
The routes must have different prior extremum sequences. They must then enter
the same future drive/query schedule with at least three later distinct drive
values.

If such pairs exist, compare the complete future response vector pointwise and
report all pairs, not a selected maximum. If no such pair exists, the causal
history coefficient is unidentified. Approximate endpoint matching may be
reported descriptively but cannot pass D3 because no joint measurement-error
or covariance model is frozen.

## 5. Causal admission gates

A public causal KEEP/BREAK substitute passes only if all gates pass:

1. one physical apparatus and one event-keyed chronological source schedule;
2. reversible, prospectively identifiable alternative history routes;
3. equal endpoint drive, complete deposited state word, and complete continuous
   mechanical response;
4. a common later query schedule;
5. matched work, heat, stress, support, actuator, geometry, and read
   disturbance, or measured residual bounds for them;
6. independent trials or a joint covariance/noise model supporting an
   uncertainty statement.

Failure of any gate yields PUBLIC_HISTORY_DIAGNOSTIC_ONLY or UNSCOREABLE, never
a null memory-lineage result.

## 6. Claim ceiling

This lane may establish a reproducible same-apparatus history dependence,
return-point closure or failure, and an exact public-data identifiability
frontier. It may not claim:

- a surgical whole-lineage KEEP/BREAK intervention;
- a writer-off retained-record test;
- URFT confirmation or refutation;
- a gravitational, metric, gamma, RGRL, or GFT effect;
- that the absence of required public fields is evidence for zero physics.
