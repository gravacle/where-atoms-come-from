      links 12, plaquettes 4, cycle rank 4, physical dim 16

  (a) ALGEBRAIC BOUND -- FORCED, reported so it cannot be mistaken for a result.
      region boundaries span the Z_2 space of plaquette subsets, dim 4.
      => at most 4 INDEPENDENT records. This is dim of the physical space, nothing more.

  (b) GEOMETRIC BOUND -- NOT forced. Can a set be SIMULTANEOUSLY PROTECTED?
      A set is simultaneously protectable iff some NONEMPTY bath avoids every boundary in it.

      k=1:   15 independent sets are simultaneously protectable.  example ['0'] with bath [1, 3, 4, 5, 8, 9, 10, 11]
      k=2:   96 independent sets are simultaneously protectable.  example ['0', '1'] with bath [4, 5, 9, 10, 11]
      k=3:  224 independent sets are simultaneously protectable.  example ['0', '1', '2'] with bath [5, 11]
      k=4:    0 -- NO independent set of 4 records can be protected at once.

  => GEOMETRIC CAPACITY OF THIS CARRIER = 3   (algebraic bound was 4)
     The two DISAGREE, so the limit is packing, not dimension.
