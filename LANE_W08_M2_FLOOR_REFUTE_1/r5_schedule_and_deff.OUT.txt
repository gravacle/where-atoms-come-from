== R5.3  THE d_eff RULE ON RS-P IS WRONG FOR ONE CONNECTION TYPE ==
   M2 publishes: 'RS-P (p10 = 0) -> only chi_0/chi_C = conj(W_F) survives, so d_eff = 1
   FOR EVERY CONNECTION' and codes it as d_eff = min(1, dim H).  But on RS-P the only
   live ratio is x = e^{-2 pi i alpha}: d_eff is decided by ALPHA ALONE.
   alpha = 1/2 (RATIONAL), beta = cubic irrational dim H = 1, M2's rule -> d_eff = 1
      cells with 1-|Z_k| = 0 (to 1e-15) out of 1e5: 50000   -> TRUE d_eff = 0
   alpha = cubic irrational, beta = 0             dim H = 1, M2's rule -> d_eff = 1
      cells with 1-|Z_k| = 0 (to 1e-15) out of 1e5: 0   -> TRUE d_eff = 1
   The first row is ATTAINED on RS-P and has d_eff = 0, not 1.  No table in the lane
   contains such a row, so nothing published is wrong because of it -- but the RULE as
   published is, and this lane's whole claim is that d_eff is the operative variable.
