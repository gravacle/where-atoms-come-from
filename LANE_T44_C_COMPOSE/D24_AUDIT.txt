-------------------

  additivity identity; the mirror cancellation (computed count equality); the nested-
  coverage monotonicity; the shadow pattern.
INSERTED, and labelled so at the point of use:
  - mu itself (the declared parameter) and the four benchmark mu rows.
  - the per-visit weight lambda on obstacle regions (the opacity dial).
  - the R2 opaque-source rule (a declared admissibility variant, run BESIDE R1).
  No decaying law is reported as Gamma's; no falloff exponent appears anywhere.

CHOICE LEDGER (every choice that could have gone another way)
-------------------------------------------------------------
1. Walks (with backtracking) as the admissible-string class: the transfer-matrix walk
   sum of the T-44 brief.  Self-avoiding strings are a different declared class; per-
   order identities (R1 additivity, mirror equality, count monotonicity under nesting/
   lambda) are subset/symmetry arguments that do not depend on the class; magnitudes do.
2. Venue sizes 11x5x5 and 13x7: large enough for separations to 6 hops and probe plane
   sweeps; every number exact, so size is bounded by runtime only.
3. mu rows {1/12,1/6} and {1/8,1/4}: one deep sub-critical row and the infinite-lattice
   landmark 1/(2D) per venue; both certified convergent on the finite venue (G0.3).
4. W_ord = 30 per-order table depth; W_res = 500 (3-D) / 1600 (2-D) resummation depth:
   chosen so every interval gate closes (tail bounds printed beside every use).
5. Region shapes: single-grain sources for the sweeps; one 2x2x2 block row (G1.1d) to
   show the identities are region-level, not point artifacts.
6. R2 defect reference: each alone-term computed in its own venue (only that source
   present) -- the declared reading of "compose like a source should"; the union run
   carries both sources.  The alternative (all sources always present) is a different
   declared instrument; the subset argument gives defect <= 0 for both.
7. Superposition R2 sweep geometry: B moves from A toward C on the axis (the venue is a
   box); the confound is DECLARED in the OUT file and the monotonicity is reported as
   found, not gated.
8. Obstacle chain {center} c disk c slab chosen nested so monotonicity is a theorem-
   grade subset fact; slab-1 and ring are reported beside as non-nested variants.

TOY_SEPARATION
--------------
The venues are the program's standing tiers (GR1/T43-B world block; the corner tier's
2-D string lattice), not lane-local toys; the instrument is the T-44 brief's declared
weighted string sum, shared with the sibling exponent lane.  Nothing here locates
criticality, earns an exponent, or decides which admissibility rule / encoding the
record surface enforces -- those belong to the exponent lane and the judge.  Returns
are DATA for the judge's composition question.
