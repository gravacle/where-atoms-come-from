  C.  THE GENERAL STATEMENT, NOT JUST THE LINEAR ONE.  PARSEVAL, EXACTLY.
--------------------------------------------------------------------------------------------------------
  For ANY functional f on the 2^m record configurations, expanded exactly as f = sum_S fhat(S)
  chi_S, two identities hold with no approximation:

      MEAN(f)      = fhat(EMPTY)                                  [the RECORD-BLIND part]
      VAR(f)       = sum over NON-EMPTY S of fhat(S)^2            [the RECORD-DEPENDENT part]

  so the typical value of f is  fhat(EMPTY) +- sqrt(VAR), EXACTLY, for every functional.

  ==> THE EXTENSIVE / RESPONSIVE DICHOTOMY, and it is an EXACT ARGUMENT, not a trend:
      * the only part of f that is the SAME at every configuration is fhat(EMPTY).  That part can
        be extensive, and it is RECORD-BLIND: no write changes it.  (This is C-61 at the record
        level, now as an identity.)
      * everything that RESPONDS to a write lives in the non-trivial characters, has mean
        EXACTLY 0, and therefore takes BOTH SIGNS.  A quantity with mean exactly 0 that is not
        identically 0 is positive somewhere and negative somewhere.
      * therefore NO functional of the record configuration is both RESPONSIVE TO WRITING and
        SIGN-DEFINITE IN ITS RESPONSE.  That is exactly the pair of properties a source needs.

  Verified exactly on random rational functionals (and note VAR is computed both ways):

  READ: N_+ IS extensive and IS sign-definite -- and its extensive part is the CONSTANT m/2,
  which is identical at every configuration and therefore carries no record information at all.

  column as YES, so a genuinely extensive record functional would not be missed; the finding is
  that its extensive part is the record-blind constant.

  N_+ /m = 1/2 + O(m^(-1/2)) at EVERY typical configuration.  A quantity that takes the same
  value to relative accuracy m^(-1/2) at every typical configuration cannot distinguish one
  configuration from another, which is what 'carrying record information' means.

  D.  CAN A DIFFERENT WEIGHTING ESCAPE?  THE EXACT TRADEOFF.  (drops the D-22 uniform weights)
--------------------------------------------------------------------------------------------------------
  Section A used equal weights because step 1 MEASURED Aut(carrier) transitive on records.  Drop
  that and allow ANY weights c_i.  Then, exactly:
        MAX|F| = ||c||_1 (attained at an ordered configuration)   TYPICAL |F| ~ ||c||_2 .
  and the coherence ratio is ||c||_2 / ||c||_1, which lies in [1/sqrt(m), 1] for every c.
  The lower end is UNIFORM weights; the upper end is ALL WEIGHT ON ONE RECORD.

  READ: the ratio reaches 1 only when the weight collapses onto ONE record -- participation 1 --
