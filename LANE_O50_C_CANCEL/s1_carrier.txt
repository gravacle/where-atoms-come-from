  READ: every one of the 2^{2k}-1 non-identity logical classes has an ADMISSIBLE flipper inside

  D.  CLAUSE (v), EXACTLY, ON THE TORUS.  NO CONVENTION, NO SAMPLING.
--------------------------------------------------------------------------------------------------------
  Definition used: a region is the edge set of a d x d block of sites with d < L, so the block
  lifts to the plane and is CONTRACTIBLE.  The question asked of each region is EXACT F_2 linear
  algebra: is there any Pauli supported inside the region that commutes with every stabiliser
  and is NOT a product of stabilisers?  Equivalently  dim( Pauli(region) cap N(S) ) >
  dim( Pauli(region) cap S ).  If not, no operation on that region touches any record.

    L   d  #regions  #edges  dim N cap region  dim S cap region  NON-TRIVIAL LOGICALS  clause (v) holds
    2   2         4       4                 3                 1                     2             FAILS  (d = L: WRAPS, not contractible -- positive control)
    3   2         9       4                 1                 1                     0             holds
    3   3         9      12                 9                 7                     2             FAILS  (d = L: WRAPS, not contractible -- positive control)

  READ: for every d < L the region contains NO non-trivial logical -- every Pauli in the region
  that commutes with H is a product of stabilisers, so no admissible operation on a single
  contractible region can flip any record.  CLAUSE (v) HOLDS ON THE TORUS.  The d = L rows are
  the positive control: a block that wraps is NOT contractible and DOES contain logicals, so
  the instrument registers a non-zero when one is there.

  This is homology, not convention (D-23): the flipping operators have genuinely non-contractible
  support, and the code distance is L in both directions, so both scale with L.

--------------------------------------------------------------------------------------------------------
  E.  D-22.  THE CARRIER'S SYMMETRY, REPORTED BEFORE ANY SEPARATION RESULT IS READ.
--------------------------------------------------------------------------------------------------------
  Three concrete symmetry generators are applied to the record set and the induced permutation
  of the records is COMPUTED (not asserted):
    Tr : translation by one site  -- maps each homology cycle to a parallel one
    Rt : the 90-degree rotation   -- exchanges the two homology cycles
    Dl : electromagnetic duality  -- exchanges X-type and Z-type logicals

  L = 2:  translation fixes every record CLASS: True    rotation exchanges the two records: True
  L = 3:  translation fixes every record CLASS: True    rotation exchanges the two records: True
  L = 4:  translation fixes every record CLASS: True    rotation exchanges the two records: True

  READ: translations act TRIVIALLY on record classes (they move the representative loop, not its
  homology class), and the rotation EXCHANGES the two records.  So the automorphism group acts
  TRANSITIVELY on the record set of one torus.  On k disjoint tori the permutation group S_k
  acts as well, so the automorphism group is transitive on all m = 2k records.

  D-22 CONSEQUENCE, STATED HERE AND USED IN STEP 6: because Aut(carrier) is TRANSITIVE on the
  records, EVERY scalar attached to a record by the carrier alone -- minimum weight, writer
  weight, protection distance, number of minimum-weight representatives -- takes THE SAME VALUE
  on every record.  No carrier-derived weighting can distinguish one record from another.
  This is a geometry-free direction of the carrier: a functional built from carrier data alone
  is forced to be SYMMETRIC in the records.  It does NOT make the carrier record-blind -- the
  records are distinguished from each other by nothing, but from the identity by clause (iii).
