# GL6CO Result

For the four cycle orientations, the stationary common-amplitude null and
all stated symmetries allow exactly

\[
S^TK_{\rm cyc}S=
\begin{pmatrix}
\alpha |k|^2&\eta q^T\\
\eta q&\kappa I+b|k|^2I+cD+dO
\end{pmatrix}+O(|k|^4),
\]

with five independent quadratic coefficients.  Pullback through the complete
common `T2` writer gives

\[
\mathcal H_T/\mu^2=8\kappa I
 +(-2\kappa+8b)|k|^2I
 +(-16\kappa+8c)D
 +(12\kappa+8d)O+O(|k|^4).
\]

Here `K_cyc` is the bare susceptibility
`2 Re <0|T_c R T_c'|0>` and contains no writer factor; `mu B_T` is applied
once in the displayed pullback.  The constant `8 kappa I` is retained local
susceptibility data, not a proof of masslessness or background stationarity.
The displayed pullback uses the `GL6CL` coordinate
`j_+=(j_P+j_C)/2`.  In the orthonormal common parent/child coordinate
`widehat j_+=(j_P+j_C)/sqrt(2)`, its Hessian carries `mu^2/2`, not `mu^2`.
That factor is used in every comparison with the normalized `GL6BV` contact.

The `T2` variables are off-diagonal components of a symmetric tensor, not an
ordinary vector.  The displayed block admits an `SO(3)`-covariant full-tensor
extension if and only if

\[
c+d={\kappa\over2}.
\]

This is one condition: not automatic, but possible and compatible with a
positive analytic cycle response.  Algebraic proportionality to the stronger
Fierz--Pauli reference `D-O` additionally requires `b=kappa/4`; that is not a
Ricci proof because the full `E2+T2` response and 1PI inversion are absent.
An exact full-solder test at generic momentum has rank three and nonzero
`A1/E2-T2` cross blocks, making that ceiling executable rather than verbal.

The independently reconstructed order-`h^2` contact has mismatch

\[
\Delta_{\rm ct}={8\over3}(2p-1).
\]

It may be combined with the cycle response only after both are evaluated in
one proved stationary state.  No cancellation or phase is asserted.
Moreover, the spectral cycle block scales as `h^6/U_d^7` in the isolated
strong-lock regime, versus `h^2/U_d^3` for the contact.  A generic match
therefore points beyond asymptotic single-cell strong-lock repetition to a
finite-ratio or collective same-state response (or another same-order
block); this is only a power-counting conclusion.
