# GD public spectral-payload search

This bounded no-lab lane asks one question: does a public numerical release
already contain, or make directly reconstructible, the finite-size response
packet required by GC16--GC19 for the complete FY/GC native H6 tensor source?

The answer from the inspected primary repositories is **not yet**.  The exact
diamond-ice papers remain phase/static evidence; the closest published dynamic
paper releases only figure PDFs; and the new 2026 HKU release contains derived
QFI tables rather than raw imaginary-time correlators and covariance.

The search did find a useful new executable root: the 2026 HKU software release
contains pyrochlore SSE/MDL-QMC code with time-dependent spin-correlator output
and a general ED/DSSF package.  It can shorten a future simulation lane, but it
does not currently implement the pure projected H6 Hamiltonian, the complete
native tensor source, the GC momenta/normalization, or covariance output.

This is a bounded, non-exhaustive public-readiness result.  It is not a claim
that no qualifying data exist anywhere, and it makes no pole, Ward, common-cone,
gravity, or `G` claim.
