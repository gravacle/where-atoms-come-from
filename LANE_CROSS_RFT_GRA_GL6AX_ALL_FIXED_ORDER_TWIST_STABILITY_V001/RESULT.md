# GL6AX result

## Exact result

For the native displacements `d_0=e_0`, `d_1=e_1`, `d_2=e_2`, `d_3=0`, every
finite contractible difference of two degree-two locked configurations obeys

```text
Delta N_a=0 for a=0,1,2,3.
```

On a torus the only exception is winding:

```text
Delta N_j=L_j W_j,
Delta N_3=-sum_j L_j W_j.
```

The minimum winding change has exactly `2L_min` links.  Thus every fixed
canonical word-based Schrieffer--Wolff/Kato coefficient, and each expanded
Feshbach coefficient, of order below `2L_min` conserves all port totals,
regardless of disconnected endpoint changes, folded terms, or complex
coefficients.

For any Hermitian translation-invariant finite-range locked Hamiltonian with
uniform local second-twist density `D_2`, the centered sector satisfies

```text
either dim ground >=2,
or Delta_L <=2pi^2 D_2 L0L2/L1.
```

On `(L0,L1,L2)=(m,2m^3,m)` this is `Delta_L<=pi^2D_2/m`.  The proof uses
`+/-` twist averaging, so it requires no vanishing-current or time-reversal
assumption.  Diagonal terms, local multi-loop terms, and complex Hermitian
amplitudes are included.

## Scientific meaning

The first exact GL6AW obstruction is now stable under every fixed controlled
local perturbative order.  It cannot be removed merely by adding the next
finite set of microscopic locked corrections.  A genuine escape must enter
through an all-orders finite-coupling failure, a winding or sufficiently
long-range term, a different selected sector, or the finite-volume-to-GNS
interface.

## Ceiling

No uniform all-orders convergence, exact finite-`h/U_d` dressed sector,
selected centered ground, selected-GNS mode, isotropic dispersion, common
cone, stress law, gravity, or `G` is proved.
