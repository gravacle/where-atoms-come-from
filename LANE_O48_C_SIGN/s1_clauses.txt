  WHY THE ZERO IS EXACT AT EVERY n  (an argument, then its test)
--------------------------------------------------------------------------------------------------------
  The global spin flip s -> -s leaves every bond product s_i s_{i+1} unchanged, hence leaves
  E(s) unchanged, hence maps each eigenspace to itself; it has NO fixed point in {+-1}^n; and
  it flips every s_i.  So the configurations in any eigenspace pair off (s, -s) with opposite
  s_i, and Tr(P_E Z_i) = 0 EXACTLY, for every i, every eigenspace, every n, every J.

  {s,-s} -- Z_i Z_j is CONSTANT on every eigenspace and FAILS CLAUSE (iii).  On the families
  with accidental degeneracies the constancy can break, but then the same table shows clause

  the CONTROL row Z_0 in the very same table passes both clauses.
  So the object that carries the configuration energy is a SUPERSELECTION LABEL on eigenspaces,
  NOT a written bit.  This is the fact the rest of the lane is about.
