==============================================================================
G2.3-FIXED  THE ONE THAT SEPARATES ABELIAN FROM NON-ABELIAN AT FIXED RANK
==============================================================================
THEOREM (abelian, any fibre rank n, any compact abelian G):
  if the ready state's mass lies in a SINGLE joint eigendirection -- one vertex,
  one weight -- then Z_k has exactly one character and |Z_k| = 1 for all k, so
  formation never occurs. This is 'the root can never fire' in its correct,
  rank-free form, and it is W-02's |S| = 1 case.
AT SU(2) IT FAILS, and it fails at the pinch:
  arm A  U(1)xU(1) (commuting, non-scalar)   #chars=1  min|Z_k|=1.000000000000  ->  CANNOT FIRE
     same state on a class-(1,0) vertex:      #chars=1  min|Z_k|=1.000000000000  ->  CANNOT FIRE
  arm B  SU(2) alpha=0.8 (same spectra)      #chars=2  min|Z_k|=0.696706711619  ->  FIRES
     same state on a class-(1,0) vertex:      #chars=1  min|Z_k|=1.000000000000  ->  CANNOT FIRE

  --> SAME fibre rank (2). SAME scalarity (both non-scalar). SAME spectra.
      ONE variable: [W_F,W_C]. The support-based criterion holds in arm A and
      fails in arm B. Abelianness IS load-bearing, independently of fibre rank.

==============================================================================
G2.3b  HONEST NEGATIVE: is there ANY refinement that rescues it at SU(2)?
==============================================================================
At n = 2 a state at one vertex has 2 free real parameters after norm and phase,
and the pair (|P^d z|^2 , |Q^d z|^2) supplies 2 constraints, so the two-basis
data generically determines z up to conjugation, hence determines |Z_k|. I
searched a 60 x 120 grid for a counterexample and found none: the best pair had
basis-weight mismatch 0.0e+00 and lambda difference 1.9e-08, i.e. noise.
SO: at SU(2), fibre rank 2, a CONNECTION-DEPENDENT two-basis refinement is not
falsified. What is destroyed is the CONNECTION-INDEPENDENT one. At abelian G the
weight decomposition of the fibre is fixed by the representation before any
connection is chosen, so 'where the record sits' is a property of the record.
At SU(2) it is a joint property of record and connection. Testing n = 3, where
the parameter count no longer matches:
  n=3: no near-coincident pair found in 4000 draws (search too coarse).
