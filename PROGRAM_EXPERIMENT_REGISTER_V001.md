## 1. Evidence classes

| Class | Meaning |
|---|---|
| `EXACT_MODEL` | Exact or synthetic physical-model discrimination; no empirical weight. |
| `SYNTHETIC_CONFORMANCE` | Schema/analysis fixture only; zero scientific weight. |
| `EXECUTED_PHYSICAL` | Public or archival physical outcomes were opened and analyzed. |
| `PAPER_LEVEL` | Published endpoints or aggregates were reproduced/compiled without a proof-grade native root. |
| `UNSCOREABLE` | A frozen execution stopped for missing design, custody, multiplicity, or identifiability. This is not a physical null. |
| `NEGATIVE_SEARCH` | No qualifying public root was found in the bounded search. This is not refutation of the physics. |
| `PROSPECTIVE` | A physical protocol or decisive test is frozen or specified but unexecuted. |
