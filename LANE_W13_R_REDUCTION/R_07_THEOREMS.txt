R-2.  SUFFICIENCY.                                                      [PROVED]
================================================================================
Suppose P has finitely many zeros on T^2, all of finite order, and let Z(P) be the zero set.
Suppose omega satisfies
  (D1)  ||m alpha + n beta|| >= C1 (|m|+|n|)^{-tau}   for all (m,n) != 0
        [equivalently, by Erdos-Turan-Koksma, discrepancy D_N(k omega) = O(N^{-eta}), eta>0]
  (D2)  dist(k omega, Z(P)) >= C2 k^{-sigma}          for all k >= 1.
Then S_N -> m(P).
PROOF.  Write f = log|P| and f_M = max(f, -M).  f_M is continuous on T^2; (D1) gives
equidistribution, so (1/N) sum f_M(k omega) -> INT f_M.  Since f is in L^1 (R-0), INT f_M
decreases to m(P) as M -> infinity.  It remains to show
        E_N(M) := (1/N) sum_{k<=N} (f_M - f)(k omega)   ->  0   as M -> infinity, uniformly in N.
f_M - f is non-negative and supported on {|P| < e^{-M}}.  Decompose into shells
S_i = {e^{-M-i-1} <= |P| < e^{-M-i}}, i >= 0, on which f_M - f <= i+1.  Because the zeros are
simple, {|P| < e^{-M-i}} is contained in TWO axis-parallel boxes of side r_i = O(e^{-(M+i)})
(one per zero), of total area O(e^{-2(M+i)}) -- verified analytically and against a grid in
R_06: area{|P|<delta} = delta^2/(2 pi |det|).  By the box-discrepancy bound,
        #{k <= N : k omega in S_i}  <=  #{k <= N : k omega in the two boxes}
                                    <=  N * O(e^{-2(M+i)}) + 8 N D_N.
By (D2), |P(k omega)| >= c dist >= c C2 k^{-sigma}, so no shell with M + i > sigma log N + O(1)
is ever occupied: the sum over i truncates at I_max = O(log N).  Hence
        E_N(M) <= sum_{i>=0} (i+1) K e^{-2(M+i)}  +  D_N sum_{i<=I_max} (i+1)
                = O(M e^{-2M})  +  O(D_N (log N)^2).
The first term is uniform in N and tends to 0 as M -> infinity; the second is
O(N^{-eta}(log N)^2) -> 0.  []
REMARK, AND IT IS THE POINT OF R-3: (D1) ALONE IS NOT ENOUGH, AND H2 IS WEAKER THAN (D1).
H2 gives equidistribution only; (D1) gives a RATE; (D2) is a different condition entirely and
