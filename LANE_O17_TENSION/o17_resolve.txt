  no environment (bare code)                   280                 280                yes

  single-site {X,Y,Z}                            1                   1 NO -- scalars only

3.  READ
    If {X,Y,Z} violates clause (ii) AND leaves only scalars in the commutant, then O-16
    measured the decay of an object that is NOT A RECORD for that environment. O-17 is then
    two arms run on two different (H,{L_k}) pairs, only one of which has a record at all.
