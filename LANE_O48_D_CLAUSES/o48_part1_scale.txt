     READ (from the numbers above): the uniform chain has exactly 2 site automorphisms

  1. THE CLAUSES SURVIVE AT EVERY n TESTED, EXACTLY.  For UNI and GEN couplings at n = 2..20
     and RND at n = 2..14, all n of the Z_i pass (i),(ii),(iii),(iv): the column
     max|Tr(P_E Z_i)| is the INTEGER 0 at every n, on every one of up to 524288 eigenspaces,
     and #R-all-four equals n in every row.  This is an exact integer statement, not a
     tolerance.  The largest n reached for the clause verification is n = 20 (1048576
     configurations); what stopped it was memory for the 2^n configuration table, not any
     change in the answer -- the columns are constant in n.

  2. AND THE CONTROLS IN THE SAME TABLE REGISTER.  Adding a field, H + 1*Z_0, breaks the
     global flip and the same instrument returns max|Tr(P_E R)| = 2, not 0, at every n it was
     run on, with 0 records passing clause (iv).  A non-degenerate H returns 0 records via
     clause (iii), which is P-1.  So the zeros above are measurements.

  3. THE FREE-WRITER PROPERTY SURVIVES AT EVERY n -- AND THE WRITER IS MAXIMALLY NON-LOCAL.
     The exhaustive 4^n search (n <= 9) and the exact F_2 nullspace (all n) agree on every
     row.  The admissible Pauli group has F_2 dimension n+1; exactly 2^n of its elements flip
     a given record; the MINIMUM WEIGHT of any of them is EXACTLY n, at every n, for both
     coupling sets.  ||[W,H]|| = 0 and the energy change is +0.000000.  The writer exists at
     every n; it is never local.

  4. AND IT FLIPS EVERY RECORD AT ONCE.  The last column of 1.3 is n in every row: there is no
     admissible Pauli that flips one Z_i and leaves the others alone, at any n including
     n = 2.  Clause (iv) is still satisfied -- it only asks that SOME admissible U flip R --
     but O-47's phrase 'single records flip for free' should be read as 'each record is
     individually WRITABLE, by an operator that necessarily writes all of them'.

  5. n RECORDS, ONE BIT.  Section 1.4: the terms of H have F_2 rank n-1, so n - rank = 1
     independent record bit at every n, and with generic couplings every eigenspace is
     EXACTLY 2-DIMENSIONAL.  The n records are n names for the same single bit.  The record
     COUNT grows; the record INFORMATION does not.

  6. THE JOINT CONFIGURATION STILL CARRIES THE ENERGY, AND STILL CANNOT BE MOVED FOR FREE.
     Section 1.5: at every n and both coupling sets the number of ADMISSIBLE operations that
     change any pair correlator is 0, and the cheapest operation that does change one costs
     +2*min|J| > 0.  With GENERIC couplings ALL n(n-1)/2 pair correlators are definite on
     every eigenspace; with UNIFORM couplings only 1 of them is.  O-47's two-record result is
     therefore the generic-coupling case, and it extends to every n unchanged.
