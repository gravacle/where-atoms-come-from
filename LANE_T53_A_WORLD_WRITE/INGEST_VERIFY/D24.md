# D24 — T-53A world-observation ingest adversarial log

Verifier posture: **REFUTED by default**.  This file preserves initial failures and

## Audit chronology

### D24-INGEST-001 — child-file symlink escape in initial source snapshot

- Initial observation: the first source snapshot checked only `is_file()` after rejecting
  literal absolute paths and `..`; a relative symlink could therefore select a file outside
  the observation bundle.
- Correction during audit (made by the source owner, not this verifier): `_relative_file`
  now resolves the candidate and requires it to remain under the resolved bundle root.
- Independent retest on frozen source
  `842451df14b6cf5677c99e103753daf5312c02aded93e775e4545c5c9b8afa99`:
  direct file symlink escape **REFUSED**, nested-directory symlink escape **REFUSED**, and
  two within-root symlink aliases of one source **REFUSED**.
- Disposition: corrected in the frozen snapshot; retained here because the initial failure
  occurred during this audit.

### D24-INGEST-002 — transient stored-certificate drift during source hardening

- Initial observation: while the source owner was hardening the contract, a CLI rendering
  briefly differed from the stored certificate in `input_contract_sha256`.
- Correction during audit (made by the source owner): the certificate was regenerated after
  the source stopped changing.
- Independent retest: three CLI executions are byte-identical to one another and to the
  stored certificate, SHA-256
  `497b3f875e9aaafe5e317c5b4e7d5cde81483eedaae914fa7f093d3a3ae1bdae`.
- Disposition: corrected in the frozen snapshot; retained as audit chronology.

### D24-VERIFY-001 — verifier line-wrap false negative

- Initial verifier result: the independently reconstructed actual bundle was marked failed
  because a literal protocol sentence crossed a Markdown line wrap.
- Diagnosis: the content was present and semantically exact; only whitespace differed.
- Correction: verifier protocol comparison now normalizes whitespace before checking the
  non-proof boundary.
- Retest: `actual_760_row_bundle_pass=true`.
- Disposition: verifier corrected; no source artifact defect.

## Uncorrected refuting findings in the frozen generic contract

### D24-INGEST-003 — duplicate JSON keys are accepted

- Attack: add an earlier, conflicting `schema` key at the manifest root while retaining the
  later valid key; repeat with a conflicting duplicate `units.time` key.
- Observed: both ambiguous JSON documents validate because `json.loads` silently keeps the
  last value.
- Why refuting: key-set closure occurs only after ambiguity has been discarded.  A closed
  manifest contract must refuse duplicate object member names at every nesting depth.
- Reproducer cases: `duplicate_outer_json_key`, `duplicate_nested_json_key`.

### D24-INGEST-004 — malformed unclosed-quote CSV is accepted

- Attack: terminate the file while a final quoted string cell remains open.
- Observed: `csv.DictReader` accepts the row and the bundle receives a certificate.
- Why refuting: the input bytes are malformed/ambiguous CSV.  Strict parsing is required
  before the closed header and cell contract can be trusted.
- Reproducer case: `malformed_csv_unclosed_quote`.

### D24-INGEST-005 — fragmented stages obtain full-process classification

- Attack: place `BEFORE`, `WRITE`, `HOLD`, and `READ` in four unrelated record/event rows,
  with incompatible roles, split across two samples.
- Observed: the certificate says `FULL_PROCESS_COVERAGE_ONLY` because stage membership is
  checked only as one bundle-wide set.
- Why refuting: no record/event trajectory contains the claimed formation pipeline.  Full
  coverage must require registered stage/role relationships and a complete causally joined
  trajectory at the contract's declared grouping level.
- Reproducer case: `fragmented_false_full_scope_upgrade`.

### D24-INGEST-006 — normalized values are not joined to source traces

- Attack: replace a normalized measurement with `999999`, recompute the normalized CSV hash,
  and leave the content-hashed source artifact unchanged.
- Observed: the mutated bundle validates.
- Why refuting: source hashes establish custody of two independent byte sets but do not
  establish that the normalized observations derive from the cited source.  A generic
  adapter/derivation identifier and independently executable source-to-row join are needed
  before the certificate can attest normalized provenance.
- Reproducer case: `normalized_value_not_joined_to_source`.
- Boundary note: the frozen *actual T-53A bundle* does independently rejoin all 760 rows in
  this verifier.  The defect is in the reusable generic contract, not in those row values.

### D24-INGEST-007 — manifest symlink silently re-roots the bundle

- Attack: invoke the loader on `nominal/manifest.json`, where that path is a symlink to a
  manifest and its children in another directory.
- Observed: validation succeeds because the bundle root is set from
  `manifest_path.resolve().parent`.
- Why refuting: child-file escape defenses can be bypassed at the root boundary.  If the
  caller-supplied manifest location defines the submitted bundle, a symlinked manifest must
  be refused (or the API must explicitly return and bind the real root as a different
  submission).
- Reproducer case: `manifest_symlink_re_roots_bundle`.

### D24-INGEST-008 — hard-link aliases bypass duplicate-source refusal

- Attack: list two distinct in-bundle paths that are hard links to the same inode.
- Observed: both are accepted as distinct sources; resolved-path string equality does not
  detect the alias.
- Why refuting: the contract explicitly refuses duplicate resolved sources, but a filesystem
  alias bypasses that invariant.  Compare file identity (`samefile` / device+inode) while
  validating local custody.
- Reproducer case: `duplicate_source_hardlink_alias`.

### D24-INGEST-009 — data bytes can masquerade as the protocol

- Attack: set `protocol_path` equal to `data_file` and bind the same digest to both roles.
- Observed: the CSV validates simultaneously as protocol and observation data.
- Why refuting: hashing a path does not validate protocol identity or role separation.  At
  minimum, resolved protocol/data/source roles need an explicit non-alias invariant and a
  protocol media/content contract.
- Reproducer case: `csv_data_accepted_as_protocol`.
