Corrections and failed checks preserved

1. An initial determinism command compared compact JSON printed on stdout with the
   indented RESULT.json artifact.  cmp returned exit 1 even though the before/after
   artifact hashes were identical.  The invalid format comparison was discarded; the
   two-run artifact hashes above are the determinism evidence.
2. An initial py_compile invocation used PYTHONDONTWRITEBYTECODE=1, but py_compile still
   attempted to write under the user cache and received PermissionError.  The compile

   /private/tmp/wac-t53a-pycache and passed for acquire.py, analyze.py,
   lakeshore_vsm.py, and checks_lakeshore_vsm.py.  No repository cache was created.
3. The first independent input-contract audit accepted eight invalid constructions:
   duplicate JSON names, an unterminated CSV quote, a fragmented bundle-wide
   BEFORE/WRITE/HOLD/READ union, normalized-data substitution without a source join, a
   symlinked manifest, a hard-linked source alias, and reuse of the data file as the
   protocol.  The contract was repaired with duplicate-name and strict-CSV parsing,
   event-joined full-process coverage, a registered in-process normalization adapter,
   lexical-root/symlink checks, physical-file identity checks, and a registered protocol
   marker.  The frozen pre-repair verifier remains in INGEST_VERIFY/.
4. The first post-repair audit then accepted a symlinked immediate bundle directory, a
   malformed raw Lake Shore CSV, a declared sample with no observation rows, and a
   RATE_STABILITY scope whose declared sample set was not represented.  The loader now
   refuses a symlinked submitted directory, the instrument reader uses strict CSV, and
   the observed record set must equal the declared sample set.  That refutation remains
   in INGEST_VERIFY_POST_REPAIR/.
5. The next audit showed that merely observing a declared sample was still insufficient:

   bundle's RATE row.  It also found that the instrument adapter ignored a nonempty ninth

   checked per sample, and the registered Lake Shore export header and nine-cell data

Scientific guardrail
--------------------
The measured response may support only the reported real-surface observations: opposite
writer directions leave opposite remanent states after removal of the field; a declared
small reverse pulse leaves most remanence; and a finite reverse-field scale changes the
sign.  The data lack blinded randomized write histories, an independent no-write cohort,
long-time retention, observer-fragment redundancy, and a second mechanism.  They cannot
establish a general record-formation law or universality.
