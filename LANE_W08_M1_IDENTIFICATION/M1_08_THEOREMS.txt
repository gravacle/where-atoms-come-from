T2.  THE LIMIT.  ITS HYPOTHESES, SEPARATED INTO THE HALF THAT IS FREE AND THE HALF THAT IS NOT.

  Let H := closure{ (u^k, v^k) : k in Z } <= T^2, a closed (monothetic) subgroup.  Weyl's
  criterion on H gives, for every CONTINUOUS g on T^2,
      (1/N) sum_{k<=N} g(u^k,v^k)  ->  int_H g dHaar_H          (no other hypothesis).
  H = T^2 exactly when L := {(m,n) in Z^2 : u^m v^n = 1} = {0}.

  (a) THE UPPER HALF IS FREE.  For eps>0, f_eps := max(log|P|, log eps) is continuous, so its
      orbit average converges to int_H f_eps; and log|P| <= f_eps, so
          limsup_N (1/N) sum_{k<=N} log|Z_k|  <=  int_H f_eps  --(eps->0)-->  lambda_H,
      by monotone convergence (log|P| in L^1).  NO Diophantine hypothesis is used.
      Verified: M1_03's truncation block, eps = 1e-1..1e-4, deviations 1.3e-07..8.1e-07.

  (b) THE LOWER HALF IS NOT FREE, AND EQUIDISTRIBUTION DOES NOT SUPPLY IT.

T4.  THE DURABILITY CRITERION ON K1, STATED EXACTLY.  THIS IS THE LANE'S ANSWER.

  Write chi_10 = u, chi_01 = v, chi_11 = uv for the three characters K1's incidence allows,
  S = supp(pi) subset {10,01,11}, and  G = < chi_a / chi_b : a,b in S > <= U(1).

  THEOREM.  On K1, for every connection and every ready state:
        |Omega_N| = prod_{k<=N} |Z_k| -> 0    <=>    G != {1}.
     Moreover:
        - if G = {1} then |Z_k| = 1 for every k and |Omega_N| = 1 for every N;
        - if G != {1} then sum_k (1-|Z_k|) diverges LINEARLY, with density
          c = int_H (1-|P|) dHaar_H > 0, and |Omega_N| -> 0 EXPONENTIALLY:
              limsup (1/N) log|Omega_N| <= lambda_H = int_H log|P| <= log(1 - c) < 0.
     There is no intermediate case.
  PROOF.  1-|P| is CONTINUOUS on T^2, so Weyl on H gives (1/N)sum(1-|Z_k|) -> c with no
  further hypothesis.  c = 0 iff |P| = 1 everywhere on H; since the coefficients p_a are
  non-negative and sum to 1, |sum_a p_a chi_a(h)| = 1 forces all chi_a(h) to coincide (strict
  triangle inequality), i.e. every ratio chi_a/chi_b is trivial on H, i.e. G = {1}.  If G={1}
  then |Z_k| = 1 identically.  If G != {1} then c > 0, the sum diverges linearly, no |Z_k| can
  be exempt from the T3 lemma's positivity clause in a way that matters (a zero only helps),
  and Jensen gives lambda_H <= log int_H |P| = log(1-c) < 0.  []
