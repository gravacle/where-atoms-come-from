PROP 1 (THE FAMILY).  { T unitary on C^V : T = T_S (+) I off gamma, T^L = M_gamma }
                    = { T_S unitary on C^gamma : T_S^L = W I }
                    = { V diag(w_{j_1},...,w_{j_L}) V^* : V in U(L), j in {0..L-1}^L },
w_j = rho.zeta^j the L-th roots of W.  PROOF: M_gamma is W.I ON the loop; a unitary is normal, and
T_S^L = W I says the minimal polynomial divides z^L - W, i.e. spec(T_S) is inside the L-th roots.
It is a disjoint union of flag manifolds U(L)/(U(m_0)x...xU(m_{L-1})) indexed by the multiplicity
vector; the generic component has real dimension L^2 - L (= 6 on K1's loops).  COR-F's T lies in the
generic component; M_gamma^{1/L} lies in the most degenerate one.  [checked: t1_family.OUT.txt T1.3]

PROP 2 (THE LOCAL FAMILY).  Add: T_{vu} = 0 unless u = v or (u->v) is an edge of gamma.  Write
T_S = D + N, D = diag(d_i), N_{i+1,i} = n_i.  Unit columns give |d_i|^2+|n_i|^2 = 1; columns i and
i+1 overlap only in row i+1, so conj(n_i) d_{i+1} = 0 for every i.  Hence for each i, n_i = 0 or
d_{i+1} = 0; and if any n_i != 0 then d_{i+1} = 0, so |n_{i+1}| = 1, so d_{i+2} = 0, and the
implication runs around the cycle.  THEREFORE EXACTLY TWO BRANCHES AND NO THIRD:
   (A) DIAGONAL   T = diag(d_v) with d_v^L = W          — a FINITE set, L^L members;
   (B) SHIFT      (Ts)(v_{i+1}) = n_i s(v_i), |n_i| = 1, prod n_i = W — an (L-1)-torus.
COR-F's T is the member of (B) with n_i = U_i.  [corroborated exhaustively: t1 T1.4, 91^3 grid,
exactly 2 unitary points, one per branch]

PROP 3 (WHAT INVISIBILITY IS).  Z_n(s) = s^* Q_n s with Q_n = (T_F^n)^* T_C^n.  Replacing s by
diag(e^{i phi_v}) s leaves pi fixed, so invisibility forces every off-diagonal entry of Q_n to
vanish; then Z_n = sum_v (Q_n)_{vv} |s_v|^2 depends only on class sums iff diag(Q_n) is constant on
each class.  Conversely both conditions clearly suffice.  SO:
      INVISIBILITY AT n  <=>  Q_n DIAGONAL AND diag(Q_n) CLASS-CONSTANT.
This is the instrument D(n) of PUBLISHED_CONVENTIONS.  It quantifies over ALL states, so unlike a
three-state sample it cannot return a false confirmation.

THEOREM 4 (THE STRUCTURE OF EVERY INVISIBILITY-RESTORING MEMBER).  Fix n and suppose invisibility
holds at n.  For any v not in gamma_C, column v of T_C^n is e_v, so Q_n[u,v] = conj((T_F^n)[v,u]);
diagonality of Q_n therefore forces row v of T_F^n to be diagonal for every v outside gamma_C — in
particular for every v in gamma_F \ J.  Unitarity of T_F^n then makes those rows equal to phases
times e_v, hence their columns too, so
      T_F^n = (a unitary A_n on C^J)  (+)  (a diagonal on gamma_F \ J)  (+)  I,
and symmetrically T_C^n = B_n (+) diagonal (+) I.  The cross blocks of Q_n then vanish
automatically, and the surviving conditions are exactly
   (i)   diag(T_F^n) constant on class 10, diag(T_C^n) constant on class 01;
   (ii)  A_n^* B_n = q_n I_J  (class 11 is J, so class-constancy there IS scalarity), i.e. B_n = q_n A_n.
Invisibility AT EVERY n is the case n = 1 of this, applied to T_F and T_C themselves.
