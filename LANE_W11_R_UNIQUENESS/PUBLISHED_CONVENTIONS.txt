THE FAMILY (the object of this lane). For a simple loop gamma with vertex set S, |S| = L, the
operators the brief asks me to characterise are
      F(gamma) = { T unitary on C^V : T = T_S (+) I_{V\S},  T^L = M_gamma }.
Since M_gamma is W.I on S, this is exactly { T_S unitary : T_S^L = W I_S }, i.e. by the spectral
theorem T_S = V diag(w_{j_1},...,w_{j_L}) V^*, V in U(L) arbitrary, w_j = rho.zeta^j the L-th roots
of W (rho any fixed root, zeta = e^{2pi i/L}). SAMPLED AS: Haar V (QR of complex Gaussian with the
R-diagonal phase correction) times a uniformly drawn root-assignment vector j in {0..L-1}^L.
This parameterisation is ONTO the family and is verified onto in leg T1.

THE OBSERVABLE. Z_n(s) = <T_F^n s, T_C^n s> with <x,y> = conj(x).y (numpy vdot(x,y)).
pi(s) = (p00,p10,p01,p11), the pushforward of |s_v|^2 onto the four classes
(is v in gamma_F?, is v in gamma_C?).

THE INVISIBILITY INSTRUMENT -- AND IT IS NOT THE REGISTRAR'S. The registrar tested three sampled
ready states. I test the quantifier itself. Write Q_n = (T_F^n)^* T_C^n, so Z_n(s) = s^* Q_n s.
    Z_n depends on s only through pi, FOR ALL s   <=>   Q_n is diagonal AND its diagonal is
    constant on each of the four classes.
(=>: conjugating s by any diagonal phase leaves pi fixed, which kills every off-diagonal entry;
then Z_n = sum_v q_v |s_v|^2 depends only on class sums iff q is class-constant. <=: immediate.)
So I score a member by  D(n) = ||offdiag Q_n||_F + max_class (spread of diag Q_n within that class),
which is EXACT, STATE-FREE, and cannot miss a state the way a three-state sample can.
INVISIBILITY RESTORED  <=>  D(n) = 0 for every n. Threshold 1e-9; observed values are 1e-16 or O(1).
