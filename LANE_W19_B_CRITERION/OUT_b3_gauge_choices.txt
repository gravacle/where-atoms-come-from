============================================================================================================
PART A  --  A THEOREM THAT FIXES WHAT ANY GAUGE-INVARIANT REGION ALGEBRA CAN CONTAIN
============================================================================================================

  A Pauli P_{x,z} commutes with the Gauss operator G_v = prod_{l ~ v} X_l  iff  z . G_v = 0 mod 2.
  The x-part is unconstrained.  Restricting to Paulis SUPPORTED IN R, the admissible z-vectors are
  exactly the GF(2) nullspace of the incidence matrix of the subgraph spanned by R -- that is, the
  CYCLE SPACE of R.  Hence:

     THEOREM (magnetic content = cycle space).  The gauge-invariant Pauli algebra supported on a
     link set R is generated by { X_l : l in R } together with the Wilson loops of the cycles
     of R.  It is ABELIAN -- purely electric -- if and only if R contains no cycle.

     COROLLARY.  If the system region is a single link, or any forest, then NO gauge-invariant
     magnetic (holonomy) observable is localised in it, whatever the carrier.  A holonomy record
     requires the system region to contain a closed loop, hence at least girth(G) links.

  INDEPENDENT CHECK: the algebra's z-dimension (from gf2_nullspace over Pauli strings) versus the
  cyclomatic number |R| - |V(R)| + components(R) computed by union-find on the graph.
  checked 1762 link subsets over 6 carriers:  mismatches = 0
  smallest region with magnetic content, per carrier (= girth):
     theta_6    girth = 2
     fan_3      girth = 3
     wheel_4    girth = 3
     wheel_5    girth = 3

PART A2  --  ONE OF THE FIVE CHOICES IS NOT INDEPENDENT.  RECORDED, NOT HIDDEN.
============================================================================================================

  CLAIM.  On PHYSICAL states, C5 MAG and C1 EXT give the same entropy for every region R.
  PROOF.  C5 keeps exactly the Gauss operators supported INSIDE R and drops the rest, so
  A_R^MAG is the commutant, inside B(H_R), of the interior Gauss operators {G_v}.  A physical
  state has rho_R supported in the joint +1 eigenspace H_+ of those same G_v (they act only on R).
  Compressing, P_+ B(H_R) P_+ = P_+ A_R^MAG P_+ = B(H_+), and rho_R lives there, so the two
  algebras assign it the same state and the same entropy.  QED.
  CONSEQUENCE: the published choice list, evaluated on gauge-invariant states, has FEWER
  independent members than it appears to.  C5 is reported below but carries no independent weight.
  CONTROL (this could have failed): the same comparison on UNPROJECTED random states must differ.
  max |S_MAG - S_EXT| over 270 (carrier, physical state, region) triples = 6.661e-16
  max |S_MAG - S_EXT| over 270 UNPROJECTED states, same regions = 0.287346   (nonzero: the control separates)

============================================================================================================
PART C2  --  A GAUGE-SPECIFIC DEFECT OF R_delta, AND THE REPAIR
============================================================================================================

  In BRD_W above, C3_FULL reports I(S:F_k) = 1.000000 for every fragment while H_A(S) = 2.000000,
  so R_delta = 0 by the standard rule I >= (1-delta) H(S) -- even though ONE FULL BIT, the Wilson
  loop W_01, is perfectly and redundantly recorded in every fragment.  The reason is structural:
  A_S^FULL = alg{X_0, X_1, W_01} carries TWO bits, one magnetic (W_01) and one electric
  (the centre X_0 X_1), and THE ELECTRIC BIT IS NOT RECORDABLE -- Gauss's law ties it to the rest
  of the graph.  R_delta demands the WHOLE system algebra be reproduced and therefore returns zero
  on a state that plainly has a record.
  THE REPAIR: evaluate R_delta relative to a declared POINTER SUBALGEBRA rather than all of A_S.
  Below, A_S is replaced by alg{W_01} alone; nothing else in the computation changes.
   BRD_W  Wilson-loop GHZ: all 5 plaquette holon  H(W_01) = 1.00000   I(W_01 : F) =  1.00000  1.00000  1.00000  1.00000   Rdelta = 4
   BRD_M  magnetic GHZ (all W = +1, deterministi  H(W_01) = 0.00000   I(W_01 : F) =  0.00000  0.00000  0.00000  0.00000   Rdelta = 4
   HAAR   Haar-random physical, seed 66           H(W_01) = 0.99960   I(W_01 : F) =  0.00637  0.22890  0.91739  0.99686   Rdelta = 0
   => with the pointer subalgebra declared, the Wilson-loop-GHZ state returns R_delta = 4 of 4
      and a flat curve.  The magnetic-GHZ row is the b1 trap again and is WEIGHTLESS: H(W_01) = 0
      there (the holonomy is deterministic), so "R_delta = 4" is the empty condition 0 >= 0.
      THE CRITERION NEEDS A DECLARED POINTER OBSERVABLE; in a gauge theory it cannot be
      read off the system region, because the region algebra always carries unrecordable electric
      charge alongside the recordable holonomy.
