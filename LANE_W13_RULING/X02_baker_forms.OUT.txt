  pi = K1_REG = (0, 3/10, 3/10, 2/5).  Z(P) = {(x0, conj x0), (conj x0, x0)},
  x0 = (-2 + i sqrt5)/3, a root of 3 z^2 + 4 z + 3 (X01, exact).  s0 = arg x0 =
  arccos(-2/3) = 2.300523983021862982686118

  CONNECTION f = 1.0, c = sqrt(2) (S4:603; W-10 N-4: the ONLY generic connection
  this corpus publishes).  u = e^{-i f}, v = e^{i c}.  BOTH ARE TRANSCENDENTAL
  (Lindemann-Weierstrass).  THAT IS NOT THE QUESTION.  The forms are:

  (D2), first coordinate.   dist over the first circle from arg(u^k) = -k f to +-s0:
        Lambda = -k f -+ s0 + 2 pi n .        Multiply by i:
        i Lambda = (-i k f)  -+  Log(x0)  +  n (2 pi i)
                   \_______/     \______/       \______/
                    beta_0        log of an      log of 1
                    ALGEBRAIC     ALGEBRAIC      (a period)
        beta_0 = -i k f is ALGEBRAIC because f = 1 IS ALGEBRAIC, and non-zero for
        k >= 1; height ~ k.  Log(x0) and 2 pi i are Q-LINEARLY INDEPENDENT because
        s0/2pi is irrational, which is NIVEN's theorem applied to cos s0 = -2/3.
        => BAKER's theorem on inhomogeneous linear forms gives |Lambda| > C H^{-K},
        H = max height ~ k, hence (D2) with tau2 = K.

  (D2), second coordinate is the same form with f replaced by c = sqrt(2), which is
        also ALGEBRAIC, and with the second zero coordinate y0 = conj(x0).

  (D1).  || m alpha + n beta || = |(-m + n sqrt2) - 2 pi q| / 2pi.  Multiply by i:
        i Lambda = i(-m + n sqrt2)  -  q (2 pi i) ,   beta_0 = i(-m+n sqrt2) != 0
        ALGEBRAIC of degree <= 4 and height << max(|m|,|n|)^2; one logarithm, 2 pi i.
        Same theorem.  => (D1) with some effective tau1.
        SANITY CHECK ON THE SHAPE:  at n = 0 this is |m - 2 pi q| and the bound is
        the classical EFFECTIVE IRRATIONALITY MEASURE OF pi (Mahler 1953: exponent
        42; Salikhov 2008: 7.6063...), which is exactly a bound of this shape.

  WHAT THE FORM NEEDS, AND WHAT IT DOES NOT.  It needs the two loop ANGLES f, c to
  be algebraic reals and the zero's coordinates to be algebraic (X01: they are, for
  every rational pi).  It does NOT need u, v to be algebraic — indeed if f and c
  are algebraic and non-zero then u and v are transcendental, and that is the
  regime in which beta_0 is algebraic and non-zero.
