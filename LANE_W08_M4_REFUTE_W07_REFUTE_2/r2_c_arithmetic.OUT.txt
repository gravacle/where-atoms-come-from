  window eps = 5.8561e-10,  K = 4000,  K*eps = 2.3424e-06
  Weyl's theorem says #{k<=K : ||k theta|| < eps}/K -> 2 eps as K -> infinity at FIXED eps.
  Effective forms (Erdos-Turan) need K eps >> 1 to say anything about the count; here
  K eps = 2.342e-06 << 1, so equidistribution has NO content at this window and this K.
  It is also the wrong KIND of statement: for a FIXED irrational theta the count is not a
  random variable and has no 'expected' value.  Two correct arguments, both computed here:

      E[#{k<=K : ||k theta||<eps}] = sum_k P(||k theta||<eps) = 2 K eps  (exact, no Weyl),
      = 4.6849e-06;  Markov: P(count >= 1) <= 4.6849e-06.
      empirical over 200000 Lebesgue draws: 0 hits (bound predicts <= 0.94).

      generic connections are named algebraic irrationals (sqrt2/sqrt3 at leg E, phi at

      K*min is O(1) in every row -- the Liouville/CF bound, deterministic.  W-07's control

== C5  WHERE THE COUNTEREXAMPLE LIVES — THE STRUCTURE OF THE EFFECT SET ==
  E(K,eps) = {theta : exists k<=K with ||k theta|| < eps} = union over k<=K, |j|<=k of
  the interval (j/k - eps/k, j/k + eps/k).  It is a union of intervals CENTRED AT RATIONALS
  OF DENOMINATOR <= K, and nothing else.
    |E| <= 2 K eps = 4.6849e-06   (Lebesgue measure, K=4000, eps=5.856e-10)
    M4's counterexample theta = 1/4 + 4.1421e-14 sits at distance 4.142e-14 from 1/4,
    i.e. inside the interval of half-width eps/4 = 1.464e-10 around the order-4 rational.
    Every irrational counterexample to 'finite order' at fixed (K,tol) is, necessarily, a
    point within eps/q of a rational of denominator q <= K.  So the corrected name is not
    a rival to 'order' but its tolerance-aware closure: PROXIMITY TO A LOW-ORDER RATIONAL,
    of which finite order is the eps -> 0 limit.  M4-1's verdict word -- W-07's name is
    'WRONG' -- is stronger than what the mathematics supports; 'INCOMPLETE: needs the
    quantifiers ord <= K and the tolerance eps' is what the decisive test establishes.
