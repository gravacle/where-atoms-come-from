`F3-MATERIAL-DUAL-CLOSURE` working law.  It does not select an elastic
profile, add a microscopic position grid, or alter bare F3.  It makes
explicit the operational condition that the law already requires for the
overlap coframe: every physical owner is supplied by the same covariant
material parent through the record-derived metric, not through an independent
coframe representative.

descent identity if and only if the complete owner census is present and has
no representative-only `E` owner.  It does not yet compute the numerical
