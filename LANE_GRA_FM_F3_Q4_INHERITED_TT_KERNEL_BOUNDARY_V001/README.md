# GRA-FM inherited TT-kernel boundary

This lane performs the first inherited interaction calculation after the
Gaussian-Maxwell composite pole screen. It does not add a tensor interaction.

Run:

```text
python3 LANE_GRA_FM_F3_Q4_INHERITED_TT_KERNEL_BOUNDARY_V001/verify_inherited_tt_kernel_boundary.py
```

The packet proves the exact order-eight octagon coefficient, classifies every
order-eight projected endpoint, and proves the complete order-eight diagonal
is scalar. It also shows the narrower spectral boundary: a susceptibility
truncated strictly at one bare order-eight insertion does not establish a new
isolated tensor pole; a nonperturbative solution of the finite-order
Hamiltonian is not excluded from doing so. The leading order-six compact ring
model is already the first inherited non-Gaussian microscopic interaction,
even though its strict infrared fixed point is Gaussian Maxwell.
