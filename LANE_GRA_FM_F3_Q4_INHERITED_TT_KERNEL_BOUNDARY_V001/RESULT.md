# Result

The unchanged F3 parent has now been classified through order eight on
supplied finite coordination-four, degree-two diamond ice. At that order the
only projected operator types are a scalar diagonal, dressed existing
hexagon transitions, and new alternating octagon transitions. The complete
diagonal remains scalar, so

\[
 \boxed{V_8=0}.
\]

Every one of the `8!=40320` irreducible paths around an alternating octagon
can be summed exactly. At symmetric detuning,

\[
 \boxed{J_8={429h^8\over16U_d^7}},
 \qquad
 H_{8,\rm oct}=-J_8\sum_{C_8}B_{C_8}.
\]

This is the first new loop topology beyond the inherited sixth-order
hexagon law. It is not the first non-Gaussian interaction: the exact
hard-core compact hexagon Hamiltonian at order six is already interacting;
Gaussian Maxwell is its infrared fixed point. Consequently the first
continuum TT matching target is the connected amputated four-point function
of that existing pure-ice model, with the octagon and hexagon-dressing terms
entering as order-eight corrections.

The order-eight loop operators can yield a nonzero analytic **bare** even/TT
two-photon vertex. The susceptibility truncated strictly at one insertion has
no new Bethe--Salpeter denominator and therefore does not establish an
isolated helicity-two pole. This is not an all-settings no-pole theorem: the
finite-order Hamiltonian, solved nonperturbatively or iterated in a
Bethe--Salpeter/Dyson equation, can in principle bind a state or shift an
existing pole, and its dressed massless 1PI kernel need not be analytic at a
threshold. The missing calculation is the commonly normalized connected TT
four-point function, followed by external-leg amputation, extraction of the
two-particle-irreducible TT kernel, resummation or finite-volume spectroscopy,
a nonzero thermodynamic residue, a common cone, and a protecting rank-two
Ward/constraint test. This can be computed without a laboratory on the
already fixed Hamiltonian; no new interaction or model machinery is needed.
