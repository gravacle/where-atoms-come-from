starting point is NOT free: it is 0, and 0 is tied to theta only in the sense that it is
the same point for every theta.  Birkhoff's theorem fixes theta and varies the start;
here the start is FIXED at 0 and theta varies.  See W13C_04, item (4) of the brief.

on T^2 with equality only where all occupied characters coincide.  This one-sided bound
