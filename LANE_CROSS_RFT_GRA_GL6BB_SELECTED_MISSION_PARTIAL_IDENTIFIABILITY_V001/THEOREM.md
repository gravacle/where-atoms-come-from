## 3. Sharp state-free non-identifiability

Fix any finite collar, any `R>0`, and any finite `s`.  Put

\[
 A_{R,s,L}:=\tau_s^{(R,L)}(M_\beta).                          \tag{BB11}
\]

Unitary conjugation preserves the spectrum of `M_beta`.  Therefore
`A_(R,s,L)` is a Hermitian unitary with both eigenvalues `+1` and `-1`.
Over the density matrices not excluded by the current state contract,

\[
 \boxed{
 \left\{q_L(R,s,\omega_L):\omega_L\ \mathrm{a\ density\ state}\right\}
 =[0,1].}                                                     \tag{BB12}
\]

The endpoints are attained algebraically by normalized vectors in the two
spectral subspaces of `A_(R,s,L)`.  This proves sharpness as an
**identifiability statement about present custody**; it does not assert that
the formation packets authenticate preparations of every such eigenvector.

The same argument applies directly on every complete finite exterior

`sigma_obs` still cannot improve the universal binary-probability interval

\[
 \boxed{0\le p_+^\Omega\le1.}                                \tag{BB13}
\]

The collar theorem does not repair missing state identifiability: adding any
nonnegative exterior error to the exact interval (BB12) and clipping to
probabilities returns (BB13).

## 4. Strongest pointwise robust interval inherited from `GL6BA`

Let `mathcal C` be any prospectively supplied set of admissible triples
`c=(R_c,s_c,omega_c)` for one fixed collar and complete finite FPSS exterior.
No independence between its entries is assumed.  Define

\[
 \boxed{
 \begin{aligned}
 \underline p_L(\mathcal C)
 &=\max\left\{0,\inf_{c\in\mathcal C}
 [q_L(R_c,s_c,\omega_c)-\varepsilon_L(R_c,s_c)]\right\},\\
 \overline p_L(\mathcal C)
 &=\min\left\{1,\sup_{c\in\mathcal C}
 [q_L(R_c,s_c,\omega_c)+\varepsilon_L(R_c,s_c)]\right\}.
 \end{aligned}}                                               \tag{BB14}
\]

Then every mission represented in `mathcal C` satisfies

\[
 \boxed{p_+^\Omega\in
 [\underline p_L(\mathcal C),\overline p_L(\mathcal C)].}     \tag{BB15}
\]

Equation (BB14) keeps the pointwise correlation between a collar value and
its own exterior error.  Replacing it by separate extrema of `q_L` and
`epsilon_L` is valid but generally weaker.  Given only (BB03) for each triple,
no smaller closed interval is licensed without additional sign or
cancellation information about the exterior error.

A useful state-robust specialization needs less than exact tomography.  If a
declared reference state `widehat omega_c` obeys

\[
 D_{\rm tr}(\omega_c,\widehat\omega_c)
 :={1\over2}\|\omega_c-\widehat\omega_c\|_1\le\eta_c,         \tag{BB16}
\]

then binary measurement contraction gives

\[
 |q_L(R_c,s_c,\omega_c)
 -q_L(R_c,s_c,\widehat\omega_c)|\le\eta_c.                    \tag{BB17}
\]

Thus (BB14) remains valid after replacing each exact collar value by the
interval

\[
 [\widehat q_c-\eta_c-\varepsilon_L(R_c,s_c),
  \widehat q_c+\eta_c+\varepsilon_L(R_c,s_c)],
 \quad
 \widehat q_c=q_L(R_c,s_c,\widehat\omega_c).                  \tag{BB18}
\]

For the unselected two-member set (BB07), exact `s`, and one reference state,
this becomes the convex-hull interval obtained by taking the minimum lower
endpoint and maximum upper endpoint over `R=2,5/2`.  Selecting a member
removes that discrete hull; it does not alter either member's dynamics.

\[

The supplied calculator evaluates (BB22) with an exact rational Taylor

`G=N(7-N)`.  On the symmetric collar,

\[

Therefore

\[
 \boxed{1-{1\over3R}\le q_0^{\rm blank}(R,s)\le1

In particular,

\[

This bound is conservative and is not asserted to be the orbit minimum.

   \[

A target-probability expectation supplied after the evolution would be
formally sufficient but circular; (BB33) is the shortest reusable
pre-evolution completion.  Numerical tolerance is not physical data.
