D3  CANONICITY THEOREM FOR T -- AND IT CUTS FOR THE REGISTRAR, NOT AGAINST IT
    THEOREM (proved here, verified below).  Let gamma be a cycle w_0->...->w_{L-1}->w_0,
    L>=3.  Let A be unitary, identity off gamma, with support inside gamma contained in
    the diagonal together with the loop's own directed edges (each fibre value either
    stays put or moves one edge forward).  Then A is EITHER diagonal OR a pure shift.
    PROOF. On the loop A[j,j]=d_j, A[j+1,j]=t_j, all else 0.  Columns j and j+1 overlap
    only in row j+1, so orthogonality gives conj(t_j) d_{j+1} = 0 for every j.  If some
    t_j != 0 then d_{j+1}=0, so |t_{j+1}|=1 by normalisation, so t_{j+1} != 0; going
    round the cycle kills every d and forces |t_j|=1 for all j -- a pure shift.  Else
    every t_j = 0 and A is diagonal.  QED  -- no intermediate 'partly moving' unitary.
    COROLLARY.  Adding A^L = M_gamma: the shift branch has prod t_j = W_gamma, and if
    each t_j is required to be a function of its OWN edge's transport U_e alone then
    t_j = zeta*U_{e_j} with zeta^L = 1: T IS UNIQUE UP TO AN L-TH ROOT OF UNITY.
