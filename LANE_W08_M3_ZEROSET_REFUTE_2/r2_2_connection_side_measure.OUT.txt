R2-2  THE CONNECTION-SIDE FIRING REGION DOUBLES WHEN A SPECTATOR VERTEX IS ADDED
====================================================================================================
numpy 2.0.2 ; IEEE double for grid checks; counts are exact integers; measures proved on paper.

PROOF, FOUR CLASSES.  The coefficients are z = (1, u, v, uv) with u = e^{-if}, v = e^{ic}.
Because 1*(uv) = u*v, BOTH PAIRS {1,uv} and {u,v} have the same product, so both pairs are
exchanged by the SAME reflection R(z) = (uv) conj(z), i.e. reflection in the line at angle
m = arg(uv)/2.  Rotate by e^{-im}: the four points sit at angles  +-m  and  +-e  with
      m = (c-f)/2 ... i.e. arg(uv)/2      e = arg(u/v)/2 = -(f+c)/2 ,
a MIRROR-SYMMETRIC configuration about the real axis.  If an OPEN half-plane H contains all
four, so does conj(H), hence so does H n conj(H) -- and that intersection is an open wedge
symmetric about the real axis (on the + side or the - side), of half-angle < pi/2.  Hence
      0 NOT in conv   <=>   cos m and cos e are BOTH > 0, or BOTH < 0   <=>   cos m cos e > 0.
And  cos m cos e = (cos(m+e) + cos(m-e))/2 = (cos f + cos c)/2  after substituting
      m+e = (c-f)/2 - (f+c)/2 = -f ,     m-e = (c-f)/2 + (f+c)/2 = c .
THEREFORE   0 in conv{1,u,v,uv}   <=>   cos f + cos c <= 0.   [R2-2A]
Its Haar measure is EXACTLY 1/2: (f,c) -> (pi-f, pi-c) is measure preserving and sends
cos f + cos c to its negative, so the two closed regions have equal measure and overlap in
the null set {cos f + cos c = 0}.

PROOF, THREE CLASSES (K1).  Coefficients {uv, u, v} at angles s+t, s, t with s=-f, t=c.
Rotate by e^{-i(s+t)/2}: angles become  m = (s+t)/2  and  +-e  with e = (s-t)/2.  Only ONE
mirror pair now, so the above collapse does not happen.  With eps = |e| reduced to [0,pi]:
  eps <= pi/2 : the gap NOT containing 0 has width 2pi-2eps >= pi and m must split it:
                m in [pi-eps, pi+eps], an arc of length 2eps.
  eps >  pi/2 : the gap containing 0 has width 2eps > pi and m must split it:
                m in [eps-pi, pi-eps], an arc of length 2(pi-eps).
m is uniform on [0,2pi) and eps has density 1/pi on [0,pi], independently, so
  P = (1/pi) int_0^{pi/2} (2 eps)/(2pi) d eps + (1/pi) int_{pi/2}^{pi} 2(pi-eps)/(2pi) d eps
    = (1/pi^2)(pi^2/8 + pi^2/8) = 1/4   EXACTLY.   [R2-2B]
