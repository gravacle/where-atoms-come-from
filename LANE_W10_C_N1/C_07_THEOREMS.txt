  D-1  The first run of C_05 leg 4 computed np.mod(k*(0.5+delta*sqrt2), 1.0) in float64.  At
       k = 1e7 that product is ~5e6, whose float64 ulp is ~1e-9 — LARGER than the k*delta being
       measured.  The delta = 1e-12 and 1e-15 rows of the first run were float noise.  Fixed by
       splitting the phase exactly as (k mod 2)/2 + k*delta; the fix and the reason are in the
       script's docstring.  The corrected rows differ from the defective ones in the third
       decimal (e.g. delta=1e-15, N=100: -14.892039 first run vs -14.903434 corrected).
  D-2  The first run of C_03 section 4 tested the zero-set criterion against a numeric minimum
       with a 1e-3 threshold and reported 453 disagreements in 200000.  That was a BAD TEST, not
       a bad criterion: an 8192-node grid cannot land within 1e-3 of a simple zero.  Replaced by
       (a) analytic-vs-numeric min|P| on the no-crossing draws (max deviation 1.6e-07) and
       (b) a grid SIGN-CHANGE test on the affine |A|^2-|B|^2, which agrees 20000/20000.
  D-3  C_03's Jensen node grid originally started at t = 0, which lands exactly on a degenerate
       P's zero and returned -inf for the SENSE C row.  Nodes are now offset by half a step;
       the offset is stated in C_00 as a convention, because it is one.
  D-5  C_07's first draft asserted B4's min|P| = 1/3, the ENDPOINT value of ||A|-|B||, without
       checking for an interior critical point.  There is one: 3 sqrt(2+2c) = sqrt(10+6c) gives
       cos t = -2/3 and min|P| = sqrt(6)/9 = 0.2721655269759087, confirmed against a 2e7-node
       scan.  The verdict (B4 is zero-free) is unchanged; the number was wrong by 22%.
       ASSERTED-NOT-COMPUTED, the corpus's own recurring defect, committed in this lane.
  D-4  C_06's power-law fit to the Boyd-Lawton error would have manufactured an exponent for the
       zero-free rows, whose errors reach the root-finder's float64 floor (~1e-12 at degree 987)
       by relation size 21-34.  The fit is now restricted to errors above 1e-9 and the floor is
       printed.  The zero-free slopes (-7.7, -7.6) are fitted over 4-5 points and are NOT a
       defensible exponent; they are only evidence that the decay is much faster than the ~n^-2
       of the zero-having rows.
