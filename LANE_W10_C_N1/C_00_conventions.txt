THE OBJECTS (register head W-09 / W-08 M1 T1, restated).

Characters, one per vertex class by (is v in gamma_F ?, is v in gamma_C ?):
    class 00 -> 1        class 10 -> u = conj(W_F)      class 01 -> v = W_C      class 11 -> uv
Per-cell branch comparison
    Z_k := <M_dF^k s, M_c^k s>  and the claim under test is  Z_k = P(u^k, v^k)
with
    P(x,y) = p00 + p10 x + p01 y + p11 xy,     p_ab = sum of |s_v|^2 over vertices of class ab.
Record  Omega_N = prod_{k<=N} Z_k.   N1: lambda = m(P), the logarithmic Mahler measure.
CONVENTION OF RECORD (M1 T1 convention A): u = conj(W_F), v = W_C.

BRANCH OPERATORS (W-01 / S3, carrier-independent form).
    (M_gamma s)(v) = W(gamma) s(v)  if v is a vertex of gamma;  s(v) otherwise.

QUADRATURE.  2D grids on log|P| are avoided entirely (log singularities; W-09).  Every Mahler
measure here is computed by the JENSEN REDUCTION
    m(P) = (1/2pi) INT_0^{2pi} log max( |p00 + p10 e^{it}| , |p01 + p11 e^{it}| ) dt
which is exact because m(A(x) + B(x) y) = (1/2pi) INT log max(|A|,|B|) dt by Jensen in y.
Trapezoid on a periodic integrand; convergence in n is PRINTED, never assumed.

THE ONE VARIABLE, PER COMPARISON.  Stated in the isolation ledger, C_07 section 6.  Every
comparison in this lane prints the two arms' parameter vectors and ASSERTS they differ, because
the corpus's commonest fatal defect is a control whose arms are byte-identical.
