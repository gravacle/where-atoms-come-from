(1c) INDEPENDENT EXACT ASYMPTOTICS.  Derived here, not taken from the lane.
--------------------------------------------------------------------------------------------------------------
  f(c) = -(1/b) ln 2cosh(b E),  E = sqrt(e^2 + lam^2 c^2)  ->  f(c) ~ -lam|c| for large |c|.
  c = sum of N iid +-1  ->  c/sqrt(N) -> Normal(0,1),  density at 0  p(0) = 1/sqrt(2 pi N).
  J_2(N) = 1/2 E[f(c''+2) - f(c'')] with c'' a sum of N-2 signs
         ~ -(lam/2) E[|c+2|-|c|] = -(lam/2)(4 p(0)) = -2 lam / sqrt(2 pi N)   -> EXACTLY N^-1/2
  sum_pairs |J_2| ~ (N^2/2)(2 lam/sqrt(2 pi N)) = lam N^{3/2}/sqrt(2 pi)      -> EXACTLY N^+3/2
  std(Phi)  ~ lam * std(|c|) = lam sqrt(N) sqrt(1 - 2/pi)                     -> EXACTLY N^+1/2
  spread(Phi) ~ lam N + const                                                 -> EXACTLY N^+1

(1e) IS THE 'SATURATION' AN ORDINARY BOUND?  chi(register:bath) <= S(bath) <= nq bits.
--------------------------------------------------------------------------------------------------------------
   lane's 'exact bound' nq(1-S(tau))  = 2.5182003436
   textbook Holevo ceiling log2(dim bath) = 3.0000000000 bits (3 qubits)
   per-site  1 - S(tau_j) for e = 1.0, 1.4, 0.7 : 0.870021, 0.964910, 0.683270
   => the ceiling is S(rho_bar) - S(tau) summed over bath qubits: this is the ORDINARY

      The lane says as much; but 'SATURATING' is therefore not a discovery about records.
