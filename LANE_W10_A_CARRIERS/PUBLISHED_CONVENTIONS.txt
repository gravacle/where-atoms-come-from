CARRIER CONVENTIONS (mine; S4 published none of its incidence, only the derived rows)

  A carrier is (V, edges, faces, gamma_F, gamma_C).
  edges[e] = (tail, head), an ORIENTED 1-cell.
  faces[f] = list of (edge_index, sign): the signed edge chain of the attaching cycle,
             sign +1 if the face traverses the edge along its stored orientation, -1 against.
  gamma_F, gamma_C are supplied the same way: signed edge chains, VERIFIED against d1/d2,
             never asserted.

  d1[v,e] = +1 if v = head(e), -1 if v = tail(e)   (head minus tail; S1:57 convention).
  d2[e,f] = signed multiplicity of edge e in face f's attaching chain.
  RANKS OVER Q by fraction-free Gaussian elimination on Fraction.  No SVD, no float rank.

  b0 = V - rank d1 ;  b1 = (E - rank d1) - rank d2 ;  b2 = F - rank d2 ;  chi = V - E + F.
  gauge parameters      = V - b0                (global phase per component acts trivially)
  gauge invariants      = E - (V - b0)          (= cycle rank of the 1-skeleton)
  curvature invariants  = rank d2 ;  flat invariants = b1 ;  curv + flat = inv is ASSERTED.
  (These four definitions are S4:524-530's, quoted; the numbers are recomputed here.)

  VERTEX CLASS.  a_v = [v is an endpoint of some edge in the support of gamma_F]
                 b_v = [v is an endpoint of some edge in the support of gamma_C]
                 class(v) = (a_v, b_v) in {0,1}^2.
  CLASS PUSHFORWARD.  pi = (p00, p10, p01, p11), p_ab = sum of p_v over class(v) = (a,b).

THE OBSERVABLE (the brief's, restated)

  u = conj(W_F), v = W_C.  Characters: class 00 -> 1, 10 -> u, 01 -> v, 11 -> uv.
  Z_k = sum_{ab} p_ab (u^a v^b)^k = P(u^k, v^k),  P(x,y) = p00 + p10 x + p01 y + p11 xy.
  Omega_N = prod_{k=1..N} Z_k.        lambda = lim (1/N) log|Omega_N|.
  PARAMETRISATION USED IN CODE: alpha = arg u, beta = arg v, so f = -alpha (W_F = e^{if})
  and c = beta (W_C = e^{ic}).  Every statement below is in (alpha,beta); the (f,c) translation
  is printed wherever it matters.  |Z_k| is invariant under (alpha,beta) -> (-alpha,-beta), so
  the sign convention is immaterial to every modulus claim and this is checked, not assumed.

  RELATION LATTICE (W-03's own term, REGISTER:239): L = {(m,n) in Z^2 : u^m v^n = 1}.
  SUPPORT DIFFERENCE LATTICE (S4-1's object, S4:625): for S subset {00,10,01,11},
        L_S = lattice generated by { (a-a', b-b') : (a,b),(a',b') in S }.
  W-02's group G = < chi_a/chi_b : a,b in S > satisfies  G = {1}  <=>  L_S subset L.
  Both lattices are already in the register; the containment is not.

  which has no log singularity unless the two branches vanish together.

THE ONE VARIABLE, AND THE ZERO-VARIABLE TRAP THIS LANE MUST NOT FALL INTO

  Z_k depends on the carrier ONLY THROUGH pi.  Two carriers with the same pi produce
  BYTE-IDENTICAL Z_k, Omega_N and lambda.  Therefore ANY "carrier control" that holds pi fixed
  while changing the complex is a ZERO-VARIABLE CONTROL and is VOID -- it is the defect W-08's
  isolation audit found five times.  This lane never runs one.  The only sense in which a
  carrier can matter to this observable is WHICH pi IT MAKES REALIZABLE, i.e. which face of the
  3-simplex the pushforward is confined to.  Every comparison in this lane therefore moves
  exactly one thing: THE OCCUPIED CLASS SET (equivalently L_S), with the connection, the
  k-range, the evaluator and the code path held fixed and DIFFED at the bytes.
