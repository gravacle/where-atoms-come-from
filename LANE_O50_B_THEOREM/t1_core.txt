--- F4: THE LITERAL CLAUSE OF THE CANDIDATE IS FALSE ---

CANDIDATE, verbatim: "every invariant functional is CONSTANT, AND every non-constant
functional is G_W-ODD, hence has mean exactly zero over configurations, hence CANCELS."

The second conjunct does not follow.  G_W-invariance is a property of the WHOLE function;
non-constant is its negation; but a non-constant function is NOT thereby odd.  Counterexample
below, exact, at every k.

------------------------------------------------------------------------------------------------------------
 1 #{i : sigma_i = +1}                   1/2        True         True      False                        0
 2 #{i : sigma_i = +1}                     1        True         True      False                        0
 3 #{i : sigma_i = +1}                   3/2        True         True      False                        0
 4 #{i : sigma_i = +1}                     2        True         True      False                        0
 5 #{i : sigma_i = +1}                   5/2        True         True      False                        0
 6 #{i : sigma_i = +1}                     3        True         True      False                        0

READ: f = #{i : sigma_i = +1} is NON-CONSTANT and RESPONSIVE at every k, and its mean is
      k/2, which is NOT zero for k >= 1.  The literal clause is REFUTED.  What IS zero is
      the mean of its RESPONSIVE part f - <f> (last column, exactly 0 at every k).  The
      non-zero mean sits entirely in the CONSTANT, i.e. writer-INVARIANT, i.e. RECORD-BLIND
      component -- k/2 is the same number whatever is written.  That is C-61 restated.

PART 1 VERDICT
====================================================================================================
  * The GROUP-THEORETIC core of the candidate is TRUE and now proved exactly:
      independent writability => all coordinate flips in G_W => G_W acts SIMPLY
      TRANSITIVELY => #orbits = 1 => the invariant space is 1-dimensional (constants).
  * The candidate's SECOND clause as literally written is FALSE: non-constant does not
      imply mean zero.  Counterexample f = #{i : sigma_i = +1}, mean k/2, at every k.
  * The REPAIRED clause is true and STRONGER than what was asked: the write RESPONSE of
      every functional cancels exactly, and the d-weighted mean of every functional equals
      that of its invariant part, which under independent writability is a constant.
  * Therefore: RESPONSIVE and NON-CANCELLING are mutually exclusive COMPONENTS of any
      functional, not mutually exclusive functionals.  Every functional splits into a
      record-blind accumulating part and a record-sensitive cancelling part.
