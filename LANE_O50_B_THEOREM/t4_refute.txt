--- 4.0  THE RIGGING CHECK, stated first and explicitly ---

record_model.commuting_family() accepts a new record only if it splits EVERY existing joint
block into two halves of EQUAL dimension (`len(pl) != len(mi) -> reject`).  After k accepted
records every joint block inside a shell therefore has dimension dim(E)/2^k -- the table is
UNIFORM BY CONSTRUCTION, all k flips exist by LEMMA W, and the theorem holds trivially.

  => WITHIN THE PROGRAM'S OWN MACHINERY THE THEOREM IS UNFALSIFIABLE.  That is a finding
     about the machinery, not evidence for the theorem.  Everything below therefore drops
     the even-splitting demand and admits any mutually commuting set of genuine records.

--- 4.3  WHY THE CELL IS EMPTY -- and it is a PROOF, not an induction from the tables ---

Suppose all k records are independently writable.  By LEMMA W(a)=>(b) each flip_i preserves
the dimension table.  The flips generate (Z_2)^k.  For any two configurations sigma, tau the
element eps with eps_i = [sigma_i != tau_i] lies in that group and carries sigma to tau, so
the action is TRANSITIVE; the stabiliser of any sigma is trivial because eps.sigma = sigma
forces eps = 0, so it is SIMPLY transitive.  A transitive action has ONE orbit, and the
space of invariant functions has dimension = number of orbits = 1.  Hence
      indep = k  =>  orbits = 1,
with no hypothesis about the carrier at all: not stabiliser, not abelian, not finite-
dimensional beyond what the family needs.  THE FORBIDDEN CELL CANNOT BE POPULATED.

The one loophole worth naming, because it is real: the argument presumes every one of the
2^k configurations is REALISED (non-zero block).  It is: the realised set is non-empty and
closed under the flips (LEMMA W preserves dimensions, so a zero block pairs with a zero
block), and a non-empty set closed under a transitive group is everything.  So the loophole
closes itself.
