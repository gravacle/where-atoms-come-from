EXACT ARGUMENT 1 -- WHICH PAULIS ARE ADMISSIBLE.
  H = -(X^(x)n + Z^(x)n).  A Pauli P commutes with H iff it commutes with BOTH stabilisers.
  For P = (x|z):  [P, X^(x)n] = 0  iff  |z| is even;   [P, Z^(x)n] = 0  iff  |x| is even.
  So N(S) = { (x|z) : |x| even and |z| even }.  This is exact and holds at every even n.

EXACT ARGUMENT 2 -- THE MINIMUM WRITER WEIGHT IS EXACTLY 2, AT EVERY n, FOR EVERY RECORD.
  LOWER BOUND (covers NON-Pauli writers too).  A weight-1 admissible unitary U (x) I must
  satisfy [U, X^(x)n] = 0 and [U, Z^(x)n] = 0, which force [U,X] = [U,Z] = 0, so U is a
  phase and flips nothing.  Hence NO writer of weight 1 exists, of any kind.  W >= 2.
  UPPER BOUND.  The weight-2 members of N(S) are exactly X_iX_j, Z_iZ_j, Y_iY_j.  Against
  a record R = (a|b):  <X_iX_j, R> = b_i + b_j,  <Z_iZ_j, R> = a_i + a_j.  One of these is 1
  unless BOTH a and b are constant vectors -- and a,b constant means R is in {I, X^n, Z^n,
  Y^n}, i.e. R is a stabiliser, not a record (it fails clause (iii)).  So every record has a
  weight-2 writer.  W = 2 EXACTLY, INDEPENDENT OF n AND INDEPENDENT OF WHICH RECORD.

EXACT ARGUMENT 3 -- THE RECORD-RECORD SYMPLECTIC RELATION MATRIX ON SET A IS IDENTICALLY 0.

  content of RecordModel.commuting_family, and symplectic Gram-Schmidt returns the Xbar_i

  On set B the same matrix is the direct sum of k copies of [[0,1],[1,0]], so P_int = k and
  lam_max(symplectic) = 1 EXACTLY at every N -- bounded, not growing.
