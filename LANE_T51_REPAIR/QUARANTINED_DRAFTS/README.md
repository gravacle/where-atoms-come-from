# T-51 quarantined drafts

These files are byte-for-byte custody copies of the untracked `VERIFY_CODEX` and
`JUDGMENT_CODEX` drafts found beside `LANE_T51_A`. They are preserved so the
no-measurement quarantine audit is replayable from a clean clone.

They are **not admissible verification, judgment, or registration evidence**.
The drafted `ALL PASS`, C-94, C-77 increment, and T-51 completion actions are
rejected. The nested `SEALS.sha256` proves only that these custody copies retain
the bytes produced by the prior attempt; it does not validate the attempt's
predicates or conclusions.

Nothing in `ORIGINAL_LAYOUT/` may be executed, promoted, or registered. The
tracked `LANE_T51_A/VERIFY/v1_adversarial_rebuild.py` file is likewise an
obsolete, unexecuted fragment sealed with the historical builder package, not an
admissible verifier.

`INPUTS.sha256` covers exactly the six preserved draft artifacts.
