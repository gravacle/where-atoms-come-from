THE OBJECT.
  P(x,y) = p00 + p10 x + p01 y + p11 xy,  p_a >= 0,  sum p_a = 1,  (x,y) in T^2.
  N1: lambda = m(P) = (1/(2pi)^2) INT INT log|P|.
  JENSEN REDUCTION (used everywhere here, and it is the reason this lane is not grid-limited):
      P = A(x) + y B(x),   A(x) = p00 + p10 x,   B(x) = p01 + p11 x.
      For |y| = 1 the phase of y is free, so
          min_y |P| = | |A(x)| - |B(x)| |         and       max_y |P| = |A(x)| + |B(x)|,
      and, for the full distribution of |P| over the y-circle at fixed x,
          |P|^2 = |A|^2 + |B|^2 + 2|A||B| cos(phi),   phi equidistributed on [0,2pi).
      Hence  m(P) = (1/2pi) INT log max(|A(e^{it})|, |B(e^{it})|) dt,  which is CONTINUOUS,
      and the SUBLEVEL MEASURE of |P| is a ONE-DIMENSIONAL integral in closed form:
          mu(eps) := Haar{ |P| < eps } = (1/2pi) INT_0^{2pi} [ 1 - arccos(R(t,eps))/pi ]_+ dt,
          R(t,eps) = (eps^2 - |A|^2 - |B|^2) / (2 |A| |B|)   (clipped to [-1,1]).
      NO 2D GRID IS USED ANYWHERE IN THIS LANE FOR A ZERO-SET OR SINGULARITY FIGURE.
