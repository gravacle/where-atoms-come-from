LINEAGE.  Claude Opus 5.  So are W-07, W-08, W-09, all four W-10 build lanes and all eight
W-10 refuters.  This lane is LAYER TWELVE of one lineage and is NOT a lineage-independent

ROLE.  I am the synthesis.  My job is the scope table, not a build.  This lane exists only so
that the five points on which the eight refuter verdicts COLLIDE with one another, or on which
the whole scope ruling turns, are decided by my own code rather than by adjudication between
other agents' numbers.  Everything else in the synthesis is adjudication and is labelled as such.

CHARACTERS AND OBJECTS (identical to the round's brief).
  class 00 -> 1 ; 10 -> u = conj(W_F) = e^{-if} ; 01 -> v = W_C = e^{ic} ; 11 -> uv
  P(x,y) = p00 + p10 x + p01 y + p11 xy ;  Z_k = P(u^k, v^k) ;  Omega_N = prod_{k<=N} Z_k
  lambda = m(P), the logarithmic Mahler measure.

EVALUATOR.  Jensen-in-y reduction, as the brief mandates:
  m(P) = (1/2pi) INT_0^{2pi} log max(|p00 + p10 e^{it}|, |p01 + p11 e^{it}|) dt
Double precision by default; mp.dps = 40 for the 24-permutation spreads of Part D; exact
Fraction arithmetic for all rank/incidence/typing work and for Part E.

GRID AND SEEDS.  Part A: deterministic midpoint grids n x n on [0,2pi)^2 with n in
{601, 1201, 2401, 4801} — deliberately NOT the random draws all three prior runs of this
figure used.  Part D: numpy default_rng(20260816) for the single random draw (exhibit 4).
Nothing else in the lane is random.

HULL TEST.  For unit-modulus points, 0 in conv(S) iff the maximum angular gap between
cyclically-sorted points is <= pi.  This is a third algorithm, distinct from W-09's and from
lane D's two, and carries no LP tolerance.

DECLARED VACUITIES, STATED BEFORE THE NUMBERS AND NOT AFTER.
  (1) Part A's four-class "f -> -f flips 0 of n^2" column COULD NOT HAVE COME OUT OTHERWISE:
      cos f + cos c is even in f.  It is an identity, not a test, and is reported as one.
  (2) Part E is a CONTROL THAT COULD NOT HAVE FAILED.  W-08's character identity is an
      algebraic identity in the group ring with no class-count index in its proof.  It is run
      once so the number is on a page, and it is entered as a theorem, not as evidence.
  (3) Part D exhibit 3 (a probability vector is S4-invariant) could not have failed either;
      it is printed as the reference regime, not as a result.
